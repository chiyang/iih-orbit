Google 連線

首次設定：建立自己的 Google Client ID
  1. 到 Google Cloud Console 建立專案，啟用要使用的 Gmail API、Google Calendar API 或 Google Drive API。
  2. 設定 Google Auth Platform 的品牌、對象與資料存取權；外部測試模式需將使用帳號加入測試使用者。
  3. 建立「網頁應用程式」OAuth 用戶端，已授權的 JavaScript 來源加入 https://chiyang.github.io。
  4. 將 Client ID 貼到本頁保存，再分別連線所需服務。不需要 API Key 或 Client Secret。

授權到期需重新連線；授權憑證不放進備份。解除本機連線會停止同來源分頁對該服務的存取。可到 Google 帳號管理存取權 撤銷授權。
