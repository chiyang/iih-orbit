Google Calendar

將 Google 活動顯示在月曆與週視圖，點選可查看唯讀明細。本機任務的進度獨立計算。

首次設定：建立自己的 Google Client ID
  1. 到 Google Cloud Console 建立或選擇專案。
  2. 在 API 程式庫啟用 Google Calendar API。後續 Drive 備份階段才會使用 Google Drive API，也可以先啟用。
  3. 設定 Google Auth Platform 的品牌資訊、對象及資料存取權。外部測試模式請將自己的 Google 帳號加入測試使用者。
  4. 在「用戶端」建立 OAuth 用戶端，類型選擇「網頁應用程式」。在「已授權的 JavaScript 來源」加入目前來源：{{ origin }}。
  5. 複製 OAuth Client ID，貼到下方並保存，再按「連線 Google」。授權讀取月曆及識別帳號後，選擇要顯示的月曆與工作空間。
