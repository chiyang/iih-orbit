# TMU IIH Orbit 專案進度工作台

使用 Angular v22、Signals 與 Angular CDK 開發的繁體中文單機專案進度工作台。

## 開始使用

需要 Node.js 22.22.3 以上的相容版本；開發環境使用 Node.js 24.19.0。

```sh
npm install
npm start
```

在瀏覽器開啟 http://127.0.0.1:4200。

```sh
npm run check
npm test
npm run build
```

`check` 檢查 TypeScript 與 Angular 樣板；`test` 驗證日期、排序、日曆區間、備份、資料升級及同步衝突；`build` 輸出正式版本至 `dist/orbit-project-manager/browser`。

正式建置使用 `.build.env` 指定 Angular 支援的 SQLite 快取，以便在限制較多的本機環境中執行。

## 功能

- 預設五個狀態：待辦事項、進行中、待審核、已完成、封存。可自訂名稱、說明、顏色、任務類型、欄位順序與是否顯示，新增或刪除狀態；刪除時必須指定任務移至哪個保留狀態，任務不會被刪除。至少保留一個狀態。
- 「管理狀態」中的「看板顯示」可立即隱藏或顯示欄位，也可在編輯狀態時設定「隱藏此狀態欄位」。封存欄預設隱藏，既有資料沒有顯示設定時也採用此預設。隱藏只影響專案看板，各工作空間分別保存設定，任務、完成比例及清單不受影響；所有欄位隱藏時仍提供管理入口。
- 「一般任務」「已完成」「封存」三種任務類型決定進度與篩選行為，改名不會影響語意。左側的待完成、已完成與封存任務檢視只顯示對應類型的欄位，包含原本隱藏的欄位；上方導覽文字同步更新，選擇分類時顯示分類名稱。封存任務不列入完成比例、待完成數量、逾期提醒或日曆。從任務表單、清單或顯示封存欄後拖曳改至其他狀態即可恢復。
- 多個工作空間：側欄選單切換，旁邊的管理按鈕可建立、改名與刪除。每個空間獨立保存專案、任務、分類、狀態與任務順序；新空間自動建立同名預設專案。可從空白開始，或套用學程行政、學生事務、課程安排、研究計劃、軟體開發、學習進度六種樣板。刪除工作空間須輸入名稱確認，至少保留一個空間。
- 大標題顯示工作空間名稱，旁邊的編輯按鈕可改名。同一工作空間的多個專案共用看板、分類及狀態，每個任務可指定一個專案或留為「未指定專案」。
- 「新增專案」開啟管理視窗，可新增、改名、封存、還原及移除；封存專案保留任務與個別進度，但不計入所有專案的完成數、總數及百分比。移除專案保留任務、分類、時程與狀態，只清除任務的專案歸屬。過期專案操作會被阻止，避免覆蓋其他分頁的修改。
- 進度區預設為「所有專案」，向下箭頭可展開各專案的任務數、完成數、進度條，以及未指定專案的任務。已封存專案集中在可展開的區域，仍可選擇查看；封存專案的任務保留在所有任務視圖。選擇專案可同步篩選看板、清單、月曆與週視圖；篩選期間新增任務預填該專案，在所有專案下新增則優先指定同名或第一個未封存專案。進度排除已封存專案與任務，包含既有未指定任務，不因搜尋或分類篩選變動，也不採各專案百分比的簡單平均。
- 以滑鼠拖曳卡片跨欄移動，同欄內也可排序；觸控拖曳支援長按。
- 建立、編輯、刪除任務，設定描述、專案、分類、狀態、優先順序、開始日期與截止日期。
- 開始日期與截止日期各自可選擇「加入時間」；會檢查截止時間不可早於開始時間。
- 自訂分類名稱與顏色，提供六種快捷色票、顏色選擇器及六位 HEX 輸入；看板狀態也支援自訂色。管理分類提供上下移動按鈕，順序同步套用到側欄、篩選及任務編輯選單，並隨工作空間備份保存。刪除分類時保留任務，改為「未分類」。
- 子任務完成勾選與進度顯示。
- 搜尋、分類與優先順序篩選，以及「待完成任務」「已完成任務」檢視。
- 清單視圖：點欄位標題可切換升冪／降冪，支援任務名稱、專案、分類、狀態、優先順序、開始日期及截止日期。日期排序會包含時間；未設定日期排在最後。可還原看板順序，也可直接修改狀態。
- 月曆視圖與週視圖：週日開始，依週日至週六排列，提供上一期、下一期與「今天」導覽。點日期旁的加號可預填日期建立任務，點任務可編輯。
- 跨日任務顯示於開始至截止的每一天；只填一個日期則顯示於該日，兩個日期皆空白則列於「未排程」。月曆每天先顯示四項任務／活動，可逐日展開，或使用右上方「展開全部／全部收合」。
- 週視圖採用七天並列的 24 小時時間格線，每半小時一格，預設顯示上午時段。日期與全天區在垂直捲動時固定，左側時間軸在水平捲動時固定；今天及目前時間有標示。
- 週時間表高度隨視窗調整，桌面為 560–900px、手機為 440–680px。滑鼠在日期列與全天區時，垂直滾輪直接捲動外層頁面；在時間格線時捲動時間軸，到頂或到底後可接續捲動外層頁面。橫向滾動與觸控板縮放維持原有行為。
- 未加入時間的任務在上方「全天」區顯示跨日橫條；有時間的跨日任務，完整覆蓋的日期也會合併成全天橫條，只有首末日未滿一天的區段留在時間格線。重疊時段並排，午夜截止不會在隔天留下額外區段。
- 例如週三 22:00 至週六 10:00：週四、週五合併為全天橫條；週三顯示 22:00–24:00，週六顯示 00:00–10:00。跨午夜但沒有完整一天的任務仍顯示於時間格線。
- 只填一個日期且加入時間時，以「開始」或「截止」標記顯示；時間標記及短任務有最小顯示高度，標籤保留實際時間。
- 點空白時段可預填一小時任務；深夜時段會自動換算隔天截止日期。時間格可使用方向鍵上下左右移動，再按 Enter 建立任務。
- 本機任務可用滑鼠拖曳改期。月曆平移整段日期並保留時間；週時間格依抓取位置以 15 分鐘定位，保留原時程跨度，跨午夜自動調整截止日期。時間卡片拖至全天區會移除時間；全天跨日橫條平移仍保留原有首末日時段。單日全天區間拖至時間格預設一小時，多日區間保留日數，單一開始／截止日期仍是標記；未排程任務拖入後設定截止標記。拖曳期間提供目的位置標示與時間表邊緣捲動，保存時檢查任務是否已被其他分頁更新、刪除或重置。Google 活動維持唯讀，不可拖曳修改。
- 專案名稱修改、完成比例計算、逾期日期提示。
- 手機側邊欄與可水平捲動的看板、清單及日曆。
- 對話框焦點管理、Escape 關閉與減少動態效果支援。任務新增／編輯視窗寬 820px，分類、專案、狀態與工作空間管理視窗寬 760px，設定視窗寬 1040px；窄螢幕依可用寬度縮小。設定視窗固定高度為 820px，較矮螢幕限制在視窗高度減 48px，只有內容區捲動，標題、分頁及完成按鈕保持可見。
- 預設文字放大，右上角「字體」選單可即時切換特小 70%、小 80%、中 90%、標準 100%、大 115% 與特大 130%；看板、清單、月曆、週視圖與表單同步調整。
- 「設定 → 資料與備份」（右上角備份按鈕可直達）可下載全部資料，或勾選一個／多個工作空間匯出 JSON。全部備份包含字體、主題及主題色偏好；工作空間備份包含完整任務、子任務、分類、狀態、自訂顏色、日期時間與順序。
- 匯入先顯示內容預覽。工作空間備份會新增獨立副本，允許重複名稱；全部備份需檢查受影響的工作空間與任務數，輸入「取代全部資料」後才還原，並可先下載目前備份。確認期間若其他分頁更新資料，須重新確認。
- 同一瀏覽器、同一網站來源的分頁自動同步工作資料與外觀偏好；各分頁保留自己的工作空間選擇。不同任務及不同外觀欄位的修改依序套用，同一任務的過期草稿會阻止覆蓋，可載入最新版或另存為新任務。
- 右上角「設定」提供淺色、深色、跟隨系統、字體與主題色。綠、藍、紫、橙快捷主題色可即時套用，也能選擇任意六位 HEX 自訂色；側欄、專案區域與按鈕、搜尋欄、清單表頭，以及月曆／週視圖的表頭、底部與日期底色同步套用。今天、非當月日期及週末使用不同深淺，文字與標籤會依背景調整對比。
- Google Calendar 整合：Client ID 設定教學、按需授權、工作空間綁定、來源顏色與顯示開關、月曆／週視圖疊加及活動明細，提供手動或每 1／5／15 分鐘更新。Orbit 任務可移至有寫入權限的月曆；確認 Google 成功與本機保存後才移除原卡片。Google 活動也可複製為獨立 Orbit 任務，保留原活動。

設定以「外觀與閱讀、任務提醒、Google 月曆、Google Drive、資料與備份、資料重置」分頁呈現，支援方向鍵及 Home／End 切換，未送出的欄位在同一視窗中切換分頁仍保留。側欄「管理外部月曆」直接開啟 Google 月曆分頁；沒有綁定月曆的工作空間只顯示管理入口。右上角主題按鈕依淺色 → 深色 → 跟隨系統循環切換，與設定頁共用偏好並保存。

工作區提供「已逾期」及「1／3／7／30 天內到期」快捷篩選與截止日期選單，排除已完成、封存及無截止日期的任務；清單預設依截止時刻由近到遠排序，可再點表頭調整。快捷選擇只影響目前檢視，不修改已保存的預設範圍。預設三天，在「設定 → 任務提醒」可選 1／3／7／30 天，也能自訂 1–30 天，從目前時間起計算；沒有截止時間的任務算至當天結束。每 30 秒及分頁取得焦點時重算，提醒設定隨全部備份與本機分頁同步保存。截止篩選期間，月曆與週視圖暫時隱藏 Google 活動，清除篩選後恢復原本的來源顯示選擇。

右上角鈴鐺開啟「訊息中心」，整理目前工作空間的「今日開始、明天開始、下週開始、即將到期、已逾期」。工作區的「明天開始」「下週開始」可直接開啟對應清單。開始清單包含待完成 Orbit 任務及工作空間內顯示的 Google 活動，包含全天安排；跨日項目只在開始日列入，僅填截止日期的任務不算開始。下週依週日至週六計算，顯示實際日期範圍；鈴鐺數字依項目去重，不代表未讀訊息數。訊息中心以右下角獨立面板呈現，項目使用 Orbit 分類／Google 來源顏色，列表同時有兩種來源時，才在列表前顯示全部、Orbit 與 Google 篩選；有多個 Google 月曆時，可展開多選並即時過濾。選項只列出該日期範圍有活動的月曆，各列表保留自己的選擇，不改動主畫面或 Google 的顯示／同步設定。上方範圍數字保持總筆數，列表另顯示篩選後筆數。點選會在中央開啟最新任務或 Google 唯讀活動，訊息中心保持開啟，關閉明細後可接著選其他項目；截止清單也可直接套用到主畫面。

右下角提示預設啟用，有時間的安排提前 30 分鐘提示，可改為 15／60 分鐘，既有已儲存的偏好仍保留；全天安排在當日 09:00 後提示一次，可自行調整時刻。可關閉全部提示或只關閉 Google 提示，訊息中心仍可使用。只有前景分頁顯示，最多三則，點選或關閉後不再重複；有時間的安排保留開始後五分鐘補提示，全天安排保留至當天結束。編輯視窗開啟時暫緩，完成、封存、刪除、改期與來源隱藏後即時重算。多分頁與重新整理共用已送出識別，改期有新識別。提示只在程式開啟期間執行，沒有桌面通知權限要求或背景推播；訊息中心與設定內容首次開啟時才載入。詳見 [提醒設計](docs/reminder-design.md)。

Google 提醒保留目前月份及前後週的獨立查詢需求，與月曆檢視共用快取、更新頻率與同步鎖。同月使用涵蓋的查詢，瀏覽過去／未來月份不會切走近期提醒資料；跨月才調整近期需求。Google 的同步時間、離線與授權狀態可從側欄外部月曆查看，訊息中心不重複顯示。沒有近期快取時需先連線同步，無法推算尚未讀取的 Google 活動。

## Google Calendar 首次連線

任務編輯中的「移至 Google Calendar」自動選擇第一個可寫入月曆，月曆清單共用五分鐘快取，重新開啟或整理頁面可沿用，過期時自動更新。有完整起訖日期時間就直接沿用；只有截止時提供「截止前預留時間」（15／30／60／120 分鐘）、「當天全天截止提醒」及「自行安排時段」，截止日期與時間並排。首次使用另授權建立活動，每次送出重新確認寫入權限；活動顯示為有空，子任務順序與勾選記錄在描述中。Google 明細可複製成獨立 Orbit 任務；每次複製建立新卡片，Google 活動保留，兩邊各自顯示與編輯，不建立同源關係。詳見 [Calendar 移轉設計](docs/calendar-transfer-design.md)。

1. 開啟「設定 → Google Calendar → 首次設定」，到 Google Cloud Console 建立專案，啟用 **Google Calendar API**。需要雲端備份時，再啟用 **Google Drive API**。
2. 設定 Google Auth Platform 的品牌、對象及資料存取權。外部測試模式加入自己的測試使用者；建立類型為「網頁應用程式」的 OAuth 用戶端。
3. 設定已授權 JavaScript 來源。設定頁會顯示目前來源；GitHub Pages 只填 `https://帳號.github.io`，不含專案路徑。本機依 Google 官方設定加入 `http://localhost` 與 `http://localhost:4200`。[官方 Client ID 設定](https://developers.google.com/identity/oauth2/web/guides/get-google-api-clientid)
4. 若目前使用 `127.0.0.1` 且無法授權，請先下載全部備份，再以 `localhost:4200` 開啟並匯入；兩個來源的本機資料各自獨立，不能直接切換後當成原資料消失。
5. 複製 OAuth Client ID 貼進設定頁並保存，等待授權元件載入後按「連線 Google」。使用 Google Identity Services Token Model，僅請求月曆讀取及帳號識別；直接呼叫 REST API，無須 API Key 或 Client Secret。[Token Model 說明](https://developers.google.com/identity/oauth2/web/guides/use-token-model)
6. 勾選各月曆要顯示的工作空間。左側「外部月曆」提供「連線 Google」「立即同步」、來源顯示開關及更新狀態；活動以 Google 標示，可查看唯讀明細及在 Google Calendar 開啟。重新開啟程式會先準備授權元件，點擊連線按鈕才啟動授權。

「在 Google Calendar 開啟」會使用 Orbit 連線帳號的電子郵件，先經 Google 帳號入口，再開啟 API 提供的該活動網址。明細顯示預期開啟的帳號；來源與目前帳號不符時要求重新連線。瀏覽器未登入目標帳號時可能需要先登入或選擇帳號。Google 活動明細的呈現方式由 Google 決定，無法保證一定使用浮動彈窗。

直接顯示 Google 活動不會自動建立 Orbit 任務、專案或分類，也不改動看板、清單及完成比例。明確選擇「移至 Google Calendar」或「複製為 Orbit 任務」才會改動本機卡片。活動顯示依工作空間綁定，搜尋、專案及分類篩選只套用本機任務；截止篩選另暫時隱藏外部活動。全天及午夜結束使用 Google 的 exclusive end；跨日完整日放全天區，部分日留在時間格。本機時區及夏令時間轉換保留實際區間，回撥時鐘的時段標示時區轉換。

活動與來源同步游標保存在 IndexedDB 的 `iih-orbit-calendar-v1`，每個來源最多保留六段日期快取。月、週視圖共用所在月份（含前後週）的查詢，同月切換視圖及週次不另建資料副本；已有涵蓋目前範圍的快取可以直接使用，離線或授權到期也可查看。分頁共享快取並通知更新。同步作業開始後，同一來源、Client ID、帳號及資料世代的分頁共同顯示「同步中」並停用同步按鈕；新開分頁也能讀到狀態，重複手動點擊不排隊。Web Locks 使用 `ifAvailable` 保護整次同步，並以受協調的公開儲存標記支援其他環境；標記有持續更新的 90 秒期限，作業完成、失敗或正常關閉會釋放，異常中斷後可恢復。各來源取得讀取鎖後仍會再次檢查快取與日期，其他分頁在作業完成後讀取最新快取，必要的新日期範圍可接續讀取。增量同步不帶日期篩選，顯示範圍另讀取 Google 展開的重複活動實例；游標失效只重建該來源，讀取分頁中斷不取代原有快取。[增量同步規則](https://developers.google.com/workspace/calendar/api/guides/sync)

月視圖每天依「全天 Google → 全天 Orbit → 時間 Google → 時間 Orbit」排列，各來源的時間項目按當天開始時刻排序，相同時刻按標題排序。只有全天項目保留底色；時間項目用 G 或分類圓點、標題及右側開始–結束時間呈現；跨日首末日顯示當天的時間區段，只有單一時間點時標示開始／截止。跨日完整日使用全天底色，首末日未滿整天的區段顯示時間，午夜結束不多顯示一天。每天先顯示四筆，超過時可逐日展開，也可使用「展開全部／全部收合」。日期格依週數、視窗高度及字級調整；週視圖增加時間表的可見高度，並縮小每小時的間距，同時保留日期／全天區滾輪捲動外層頁面的行為。

月曆與週視圖上方提供「Google 月曆」「Orbit 任務」快捷顯示開關，可只看其中一種或同時顯示。開關共同控制全天、時間、計數及未排程區，選擇在同一分頁內切換視圖、篩選及工作空間時保留，重新整理後預設全部顯示。隱藏來源不刪除資料、不停止同步，也不改動側欄個別月曆的工作空間綁定或顯示設定。截止篩選期間 Google 開關停用並說明原因，清除篩選後恢復原選擇。

Google 月曆的同步狀態與來源資訊統一在左側「外部月曆」查看，月曆與週視圖底部不再重複顯示同步資訊列。

預設每 5 分鐘更新，設定為手動時切換日期仍會讀取該段活動。程式關閉後不繼續同步；授權到期需點擊重新連線，離線時顯示已快取日期及更新時間，沒有快取的日期會明確提示。快取保存失敗時保留分頁內活動並顯示訊息。本機解除連線會停止此瀏覽器同來源分頁的讀取，不撤銷 Google 端授權，設定頁另提供管理應用存取權的連結。

切換分頁、定期檢查及收到其他分頁同步完成通知時，先安靜讀取本機快取，只有需要向 Google 讀取資料才顯示與廣播「同步中」。取得作業鎖後會再確認快取，若另一分頁已完成更新就跳過。有效快取的檢查不發布同步開始／結束，因此不會讓分頁互相觸發同步狀態，也不會縮短設定的更新間隔。

重新整理或離開頁面時會停止本分頁的讀取並釋放同步標記；從瀏覽器上一頁／下一頁快取返回時重新檢查設定及快取。支援 Web Locks 的環境會探測作業鎖，沒有執行中的分頁就立即清除遺留標記，另一分頁仍在同步時繼續顯示同步中。替代協調的標記明確記錄鎖類型，異常中斷依 90 秒期限恢復。整次同步最多執行兩分鐘，逾時停止請求、解除同步中並顯示原因，可再次按立即同步；保留已下載的活動與仍有效的分頁憑證，晚到的舊回覆不能更新畫面或清除新作業狀態。

未到期的憑證保存於每個分頁的 `sessionStorage`（`iih-orbit-google-session-v1`），重新整理後驗證 Client ID、帳號、資料世代、權限及原到期時間再恢復。新分頁透過 BroadcastChannel 向已連線的同來源分頁請求憑證，保存於自己的 sessionStorage；不延長期限，也不把憑證寫入 localStorage、IndexedDB、匯出檔或 Drive。同來源需包含相同協定、主機及連接埠，`localhost` 與 `127.0.0.1` 不共用。[sessionStorage 說明](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage)、[BroadcastChannel 說明](https://developer.mozilla.org/en-US/docs/Web/API/Broadcast_Channel_API)

本機另保存不含憑證的公開失效識別，用於解除連線、重新授權、重置及拒絕舊副本。未收到即時通知的分頁，回到頁面或重新整理時也會重新檢查；舊 HTTP 401 或取消通知不會清掉較新的授權。關閉分頁通常會結束 sessionStorage，但瀏覽器還原分頁可能恢復內容，啟動時仍檢查期限與失效識別。瀏覽器阻擋儲存或分頁通訊時顯示提示，不改把憑證放進 localStorage；授權元件仍由按鈕點擊啟動，沒有無限期自動續期。[Google Token 到期說明](https://developers.google.com/identity/oauth2/web/guides/use-token-model)

Client ID、帳號識別、月曆綁定與更新頻率隨全部備份保存；特定工作空間備份預設只帶月曆來源，可選擇附帶公開 Google 設定，匯入時另勾選才套用。為保持備份輕巧，Google 活動快取只保存在目前瀏覽器本機的 IndexedDB，不納入檔案備份、Drive 備份或跨裝置同步，已取消附帶快取的選配規劃。Access Token 及授權狀態也不匯出；在新瀏覽器匯入或全部還原後需重新授權讀取活動，原分頁新增工作空間副本可沿用仍有效的連線。套用 Google 設定時先將更新頻率設為手動。重置清理月曆綁定、快取及分頁憑證，保留或清除公開連線設定依重置模式決定。

Google 整合目前已通過模擬授權、API、資料與同步控制器測試；使用者已回報自行測試 Calendar Client ID 連線，完整真實帳號及畫面驗收仍待完成，不能以模擬測試替代實際操作。

## 工作空間樣板（1.6.0）

在「管理工作空間」的建立區選擇樣板，可預覽分類、專案與任務。工作空間名稱可修改；第一個專案會採用輸入的工作空間名稱，其餘專案依樣板建立，所有專案共用分類與狀態。空白選項只建立同名專案。

各樣板提供四個分類、額外一至兩個專案，以及五個虛構示範任務；示範同時包含全天、指定時間、多日、子任務及不同完成狀態，日期依建立時的本機當週（週日至週六）安排。取消「加入本週示範任務」會只建立專案、分類與預設狀態。示範任務皆標註為樣板範例，可自由修改或刪除；只套用到新工作空間，既有工作空間與舊的未指定任務會保留原樣。

樣板內容在開啟建立介面時才載入；重複套用會建立獨立的識別碼，資料可照原有規則匯出、匯入與 Drive 同步。工作空間改名只修改空間名稱，不自動改動既有專案名稱。

## Google Drive 備份與同步（1.6.0）

1. 在同一 Google Cloud 專案啟用 **Google Drive API**，沿用已設定的 OAuth 網頁應用程式 Client ID，並確認本站 origin 與測試使用者已登記。
2. 開啟「設定 → Google Drive」或側欄「管理 Google Drive」，點「連線 Google Drive」授權。Drive 與月曆分別請求權限；解除其中一個不會解除另一個。Drive 使用 `drive.file`，只列出 Orbit 建立的備份，無須 Client Secret。[官方權限說明](https://developers.google.com/workspace/drive/api/guides/api-specific-auth)
3. 連線後自動讀取「雲端資料」，同一清單包含這台電腦正在使用的資料、其他電腦的資料及另外保存的備份。已有資料時按「查看並使用」，核對工作空間、任務數及外觀後，按一次「使用這份雲端資料」確認；不需輸入文字。選用最新資料會接續自動儲存，多份不同內容也能選用其中一份，其他版本保留為過去備份。兩台電腦需沿用同一 Client ID／Drive 帳號。
4. 成功確認雲端沒有資料後，才顯示「建立第一份自動儲存」。預設保存所有工作空間與設定，並接收其他電腦的更新；需要時展開「調整保存範圍與方式」，改為只選部分空間或只備份這台電腦的修改。建立前再次讀取雲端，若其他電腦已新增資料，就回到既有資料清單。已經有資料但需要獨立的新資料時，才展開「已有資料，但想另外建立一份？」。
5. 目前使用的資料就在雲端清單內，可直接立即儲存、暫停、恢復及查看內容。保存範圍、頻率、另存當下備份與整份刪除收在「儲存設定與更多操作」。同範圍沿用同一份雲端資料，更換範圍才另建一份並保留舊資料。Google 連線設定已有 Client ID 時預設收合。

清單會區分讀取中、讀取失敗及確認沒有資料。讀取失敗時保留上次的清單並標示尚未確認，重新載入成功前不提供換用或建立。只有本機舊連結而雲端資料已不存在時，顯示「本機保留的儲存連結」及清除入口，不宣稱資料正在使用。

選用所有工作空間的雲端資料會套用主題、字體、提醒與月曆顯示設定，Google 連線與 Drive 儲存頻率保留在本機。選定工作空間保留整體外觀與提醒。想保留現有資料時，在預覽的「保留本機內容或下載備份」選「加入工作空間」新增副本，或先下載目前的本機資料。過去的完整備份使用相同的確認按鈕，並說明覆蓋範圍、暫停自動儲存及需重新連線 Google；確認期間本機內容、雲端版本或授權更新時，須重新確認。

自動處理預設修改後等待 15 秒，可改為 30／60 秒；雲端檢查預設每 5 分鐘，可改為 1／15 分鐘或關閉輪詢，仍能手動處理及保存本機修改。只有程式開啟、授權有效且連線時運作；沒有背景工作或自動延長 Google 授權。未過期憑證保存於 `iih-orbit-drive-session-v1` 的 sessionStorage，同來源分頁可接續，與月曆憑證隔離。過期後按連線恢復，不將憑證放進備份或 IndexedDB。

跨裝置同步包含工作空間、任務、分類、狀態、專案與月曆綁定，並同步月曆的名稱、顏色與顯示開關。「所有工作空間與設定」另外同步主題色、深淺色／跟隨系統、字體大小、全部提醒偏好及 Google Calendar 更新頻率，接續後立即套用，只有設定修改也會上傳。選定工作空間不包含整體外觀或提醒。Client ID、Google／Drive 帳號與授權、Drive 模式／範圍／儲存與檢查頻率保留各裝置設定；外部活動快取、通知權限與已提醒紀錄不隨檔案傳送。相同共享內容不重複上傳，接收後不再回傳一次。備份格式 5 仍讀取格式 1–4；完整備份含公開 Drive 偏好，全部還原會先關閉自動處理，不攜帶同步基準或佇列。

兩台裝置各自修改時，兩份內容都會保留並請使用者選擇。只有主題色、字體或提醒設定不同，也會按相同方式處理。

「過去備份」是自動保存的歷史版本：有內容或設定修改並完成保存時，建立新的最新版本；沒有變更的內容不重複上傳。每份自動備份／同步資料保留最近 **8 份**（最新 1 份＋過去 7 份），連線讀取、重新載入及保存後自動將更舊版本移至 Drive 垃圾桶，仍可逐份手動刪除。手動另存備份不自動清理。尚有不同內容待選擇或未完成上傳的資料集暫不清理；本機同步基準及待上傳所需的舊版本會暫時保留，處理完成後再回到上限。清理失敗不影響已保存內容，顯示提示並在下次讀取重試；垃圾桶保留原內容及版本關係供同步辨識，不永久刪除。

「所有工作空間與設定」的另存備份及自動備份保存以下內容：

| 內容 | 全部資料備份 | 選定工作空間備份 |
| --- | --- | --- |
| 工作空間、專案（含封存）、任務、分類與狀態（含顏色、順序與隱藏設定） | 全部保存 | 保存勾選的空間 |
| 主題色、深淺色／跟隨系統、字體大小 | 保存 | 不包含 |
| 到期天數、提醒提前時間、全天提醒時間、彈出提醒及 Google 提醒開關 | 保存 | 不包含 |
| 公開 Client ID、帳號識別、Google Calendar 更新頻率 | 保存 | Drive 的空間備份不包含；本機檔案匯出可另外勾選 |
| 月曆來源名稱、顏色、顯示設定與工作空間綁定 | 保存 | 保存勾選空間的來源 |
| Drive 模式、範圍、修改後等待時間與檢查頻率 | 保存 | 不包含 |

自動備份追蹤全部匯出內容，包括公開連線與 Drive 偏好；跨裝置同步追蹤上列共享資料與設定，忽略每台裝置的連線和 Drive 控制設定。兩種模式都能保存外觀與提醒修改，匯出時間、程式版本及分頁選定空間不觸發重複紀錄。選定空間只偵測該範圍的內容與月曆來源。舊完整備份基準缺失時，可能追加一份紀錄建立基準；既有雲端檔案不改寫。

Drive 預覽顯示保存的主題色、深淺色與字體。「使用這份雲端資料」接續所有工作空間的同步時立即套用外觀與提醒設定；選定工作空間的同步保留整體外觀與提醒。使用過去的完整備份會套用備份中的全部資料與設定，暫停自動儲存並要求重新連線 Google。「加入工作空間」則保留目前資料與設定。

不備份 Google Access Token／授權狀態、Google 月曆活動快取、Drive 待上傳佇列與同步基準、已顯示提醒的紀錄，以及暫時的搜尋、視圖與訊息中心篩選。Google 事件保留在 Google Calendar，還原後重新授權讀取；Orbit 任務則完整保存在備份內。更換 Client ID 會關閉 Drive 自動處理並解除原授權，須重新連線、啟用後才能繼續自動備份。

每個版本保存父版本與內容校驗，判斷分歧不使用電腦時鐘。本機與雲端各自修改時，先保存本機分支，保留雲端分支並暫停自動套用；可使用目前本機、預覽後使用雲端，或先匯入雲端為工作空間副本再選本機。解決會建立連接雙方的新版本，舊內容仍保留；確認期間又有修改就重新預覽。最多一次合併 20 個分支，超過時須先匯入需要的副本再建立新集合。

同源分頁共用 Drive 作業鎖與「處理中」狀態。待上傳 JSON 與固定檔案 ID 保存在 `iih-orbit-drive-v1` IndexedDB，重新整理可重試；回應遺失時校驗同一檔案，不另建重複版本。離線的新修改仍由本機保存，恢復網路／授權後再處理。Drive 單份備份限制 20 MB，小檔使用 multipart，大於 5 MB 使用 resumable；中斷留下的空檔只補完同一待上傳版本，已完成版本不改寫。[官方上傳說明](https://developers.google.com/workspace/drive/api/guides/manage-uploads)

「雲端資料」顯示每份資料的工作空間名稱或數量、用途、最近保存時間與任務數，目前資料加上「目前使用」標示。「過去備份」與另外保存的備份預設收合，只以日期時間辨識，不顯示「第幾次保存」；每份旁都有垃圾桶，可個別刪除。開啟已連線的 Drive 面板時自動讀取一次清單，重新授權後再讀取；焦點與一般設定變更不重複讀取，仍可按「重新載入」，並顯示清單更新時間。

```text
IIH Orbit/
  同步資料/                 每個集合的最新同步版本（含尚未解決的分支）
  歷史備份/
    手動備份/
    自動備份/
    同步歷史/               已有後續版本的同步資料
```

新檔案直接存入對應子資料夾；同步版本更新後整理該集合，既有其他集合及另存備份可在「設定 → Google Drive → 檔案位置與整理」按「整理資料夾」搬移及重新命名。整理保留檔案識別碼、JSON、校驗及父版本關係，可重複執行；已在正確位置的檔案略過，不重新下載整份歷史。整理失敗與上傳失敗分開提示，已成功保存的資料不重複上傳，整理可單獨重試。資料夾調整採 Google Drive 的父資料夾更新方式。[官方資料夾說明](https://developers.google.com/workspace/drive/api/guides/folder)

在「設定 → Google Drive」展開「過去備份」，點日期右側的垃圾桶，可刪除單份備份，保留目前同步、其他備份、本機資料及尚未上傳的修改；另外保存的備份也能逐份刪除。確認區列出日期及範圍，按一次「刪除這份備份」確認即可。整份刪除也先列出完整範圍，再按「刪除這份雲端資料」確認，不需輸入文字。刪除目前正在使用的資料前，會停止自動儲存、解除連結並取消該資料的待上傳內容，其他資料與佇列保留。

出現多份內容待選擇時，直接列出每份的保存時間、預覽與垃圾桶，按「刪除這份內容」確認即可逐份刪除。目前使用的資料有多份不同內容時，也提供相同操作。只將選定檔案移至 Drive 垃圾桶，其他內容、過去備份及本機資料保留；剩下唯一最新內容時不再提供逐份刪除，以免誤刪整份資料。若剩下的內容與本機不同，會先請你確認使用本機或雲端；自動備份模式保持原設定。重新載入會更新其他裝置留下的待選擇狀態，確認期間雲端有新增、刪除或接續版本時，需重新確認。

刪除會移至 Google Drive 垃圾桶，程式不永久刪除或清空垃圾桶。單份過去備份在垃圾桶的中繼資料保留同步關係，清單不顯示、整理不搬回，也不因刪除中間備份而產生假衝突。刪除整份雲端資料另保留停止同步的識別，避免其他裝置重新建立它。本機工作空間、任務及 Google Calendar 事件保留。[Google Drive 刪除與還原說明](https://developers.google.com/workspace/drive/api/guides/delete)

確認期間雲端新增版本、待上傳內容、帳號或設定改動會要求重新確認。部分刪除失敗時顯示「刪除尚未完成」，可重新確認剩餘範圍並繼續；已移至垃圾桶的檔案略過。雲端檔案已全部消失時，「清除舊連結」可取消殘留連結及待上傳內容，重新確認清單後選用既有資料或建立新的自動儲存。同源分頁共用作業鎖與刪除後列表通知。歷史仍預設保留，不另外自動清理。

重置或全部匯入會清理本機 Drive 狀態與佇列、關閉自動處理，保留雲端檔案，之後須重新預覽接續。Drive 側欄首次閒置時載入，設定面板首次開啟 Drive 分頁才載入。真實 Drive OAuth、IndexedDB、API 與跨裝置操作仍需實際帳號驗收。

## 品牌與閱讀設定

軟體主名稱為「IIH Orbit」，機構識別為「TMU」，正式名稱為「TMU IIH Orbit」。側欄以較小、增加字距的「TMU」置於上方，下方「IIH Orbit」使用同一行粗體字。圖示採略微傾斜的橢圓軌道，圍繞中央直立的「IIH」，右上加上軌道點；圖形及字標配合主題色與閱讀大小調整。手機頂部與側欄底部使用相同軌道圖示，瀏覽器圖示採相同形狀並配合系統深淺色。瀏覽器標題與對話框保留正式名稱，專案名稱仍可自行設定。

工作空間識別使用名稱的第一個完整字元，側欄、大標題旁及工作空間管理清單採用相同的綠色圓角樣式。改名或切換時同步更新，中文、英文及表情符號皆可顯示。

側欄字標下方加入「讓每一步都慢慢上軌道」小標語，置於工作空間選單上方，以柔和文字色及緊湊間距呈現；字級隨閱讀偏好調整，最小為 10px。

側欄工作空間整個區塊可點擊開啟原生切換選單，鉛筆管理按鈕位於右上角。名稱使用完整列寬並可換行，不與管理按鈕擠在同一列；鍵盤可聚焦選單及獨立管理按鈕。

標準大小的內文為 16px、桌面任務名稱為 17px，提示文字也提高至至少 10px。六種閱讀大小以整體比例調整文字，側欄、日曆日期、全天列與時間格會隨之擴展。窄螢幕的日期與時間欄位改成上下排列，寬表格和日曆則在自身容器內水平捲動。週視圖切換字體大小時保留目前查看的時段，超過可捲動範圍時停在底部。

外觀偏好與工作資料共同儲存於 `orbit-workspaces-v2`，重新整理後仍保留，也會同步到同源其他分頁。原本 `orbit-text-size-v1` 的偏好自動讀取升級；「小 90%」改稱「中 90%」，保留舊設定的識別與比例，舊偏好及備份不會自動縮小。若瀏覽器無法保存，設定暫存在本分頁並可完整匯出。

側欄保留足以容納工作空間選單與導覽的最低寬度，特小或小字體不會將側欄一起壓窄。桌面依螢幕寬度至少為 194–220px，手機展開時至少 220px 且不超過視窗的 88%；導覽圖示與任務數固定，長文字使用省略顯示。

## 資料保存

工作空間及各自的專案、任務、分類、狀態與任務順序保存在 `localStorage` 的 `orbit-workspaces-v2`。外層保存資料世代與修訂識別，寫入前取得同源鎖並重讀最新資料，避免分頁以整份舊快照蓋掉其他修改。優先使用 Web Locks；不支援時使用 IndexedDB 交易協調寫入。更新透過 BroadcastChannel、`storage` 事件與分頁取得焦點時的重讀通知。

目前選擇的工作空間改為每個分頁自己的 `sessionStorage`，鍵為 `orbit-active-workspace-v1`；重新整理同一分頁仍保留選擇，切換不影響其他分頁。分頁同步只適用同一網站來源及瀏覽器設定檔；不同連接埠、`localhost` 與 `127.0.0.1` 的資料各自獨立。

v1 工作空間與更早的看板會先讀取升級，第一次實際修改後寫入 v2；舊鍵保留作為升級前來源。不要同時以舊版程式操作同一份資料。清除瀏覽器網站資料仍會移除看板，請先下載備份。

這是單機使用的前端版本，第一次開啟會載入可修改的範例任務。介面與資料模型已移除成員及負責人。

原本 `orbit-board-v1` 的版本 1 或 2 資料會自動升級為第一個「我的工作空間」，看板格式升級為版本 4，保留所有任務、分類、日期時間、子任務與順序，加入預設封存狀態。版本 1 沒有的開始日期與時間維持空白。原本儲存鍵及先前的 `orbit-board-v1-backup` 不會覆寫。

舊版單一專案名稱會轉為第一個專案，原有任務自動歸入；任務識別、分類、狀態、順序、日期時間與子任務保留。新增工作空間建立同名預設專案，舊有未指定任務保持原樣。工作空間備份包含專案清單及任務歸屬，匯入副本時一併重建專案識別與參照。

一般操作若無法寫入，變更留在該分頁記憶體，顯示提示並可立即匯出。匯入必須成功保存才套用；容量不足或格式驗證失敗時保留原資料。若未保存的分頁同時收到外部更新，會提示先匯出，避免靜默丟棄內容。

備份格式 `application: iih-orbit`、`formatVersion: 5`，目前版本 1.6.1；格式 1–4 的舊備份仍可匯入並升級，舊字體設定補上原本的淺色與綠色主題。新備份需使用相容於格式 5 的版本還原。僅匯入已支援的資料欄位；上限 20 MB。全部匯入同時取代資料、外觀、提醒與公開 Google／Drive 設定並建立新的世代，其他分頁更新畫面但保留未送出的任務草稿。工作空間匯入重新產生內部識別碼與月曆綁定參照，副本可獨立編輯，保留本機外觀；公開 Google 設定需另外勾選才套用。全部還原無法直接撤銷，請保留還原前備份。

「設定」的重置區提供「清空工作資料」（保留外觀、Client ID 與更新設定）及「重置整個 Orbit」（還原預設設定）。兩者都清空月曆綁定及快取，提供先下載全部備份，要求輸入對應確認文字，並檢查確認後是否有分頁更新；保存失敗不重置。成功後移除 Orbit 的舊版資料與偏好鍵，保留一份新的空白工作空間狀態，避免重新整理後載入範例或舊任務。同一來源其他程式的儲存鍵不會清除。協調寫入的 IndexedDB 只保存鎖，與月曆快取分開，維持可用以保護其他分頁。重置會停止 Google 讀取，舊世代尚未返回的請求無法重新寫回活動。

日期與時間依本機時區解讀。不設定截止時間時，以該日結束作為逾期判斷；開始日期未加入時間則視為該日開始。清單排序不會改動儲存的看板順序。
