## 統計範圍

總覽有獨立的專案選擇與「包含封存任務與專案」，不受任務清單原先的搜尋、分類、已完成或日期條件影響。預設包含未指定專案，排除垃圾桶、封存任務及封存專案；開啟包含封存後，封存內容加入分母，垃圾桶仍排除。切換回原任務視圖，原有篩選保留。

| 概況 | 計算方式 |
| --- | --- |
| 有效任務／範圍內任務 | 目前專案與封存範圍內的主任務總數 |
| 待完成／已完成 | 依實際狀態的 active／done 類型計算，不依名稱或固定 ID |
| 已逾期 | 待完成且已過實際截止時間；全天截止算至當天結束 |
| 未排程 | 開始與截止日期皆空白；只有一端日期不算未排程 |
| 有資訊連結 | 至少保留一項有效關聯的任務數；同檔重複新增事件不重複計任務 |
| 完成率 | 已完成／範圍內主任務，四捨五入；3／8 為 38%，空範圍為 0% |

子任務完成數另列，不加入主任務分母。包含封存時，封存任務不算待完成或已完成，因此在完成比例圖另列「封存任務」入口。狀態與分類分布沿用自訂名稱、顏色及順序；專案概況含各專案及未指定專案，不採百分比的簡單平均。

- 任務分類圓環圖：每個分類及「未分類」按任務數顯示占比，旁邊列出總數、已完成、待完成及完成率；包含封存時另列封存數。
- 時程長條圖：今日開始、本週開始、即將截止及逾期，共用同一數量尺度，以該範圍最多的項目為滿長。各項可能重複，不加總成比例。

圓環區塊及堆疊長條採精確任務數繪製，不使用四捨五入後的百分比。圖例比例顯示至一位小數，極小比例顯示「<0.1%」；因顯示四捨五入，圖例比例合計可能略有差異。沒有任務時顯示空圓環與 0%，單一非零類別可呈現完整圓環，零數量仍保留文字入口。

點選圓環區塊、圖例、時程長條或專案列，都會開啟相同條件的任務清單彈窗。圓環區塊可用 Tab 聚焦、Enter 或空白鍵啟用，另有原生圖例按鈕及文字標示，不只靠顏色辨識；手機、大字級與深色主題自動調整版面。圖表由本機工作資料衍生，不掃描 Drive，也不推估缺乏事件紀錄的歷史趨勢。

### 每日完成數與歷史趨勢

「完成趨勢」可選近 7／30／90 天及每日／每週；選擇 90 天時預設每週。週區間為週日到週六，期間兩端只計所選範圍內的日期。圖表以直線連接各日／週的完成數，保留零值資料點及數量刻度；只有一筆紀錄時顯示單一資料點，不繪製虛構連線。另顯示期間完成總次數與今日完成數，窄版可水平捲動。期間與彙整方式在同一工作空間的編輯、專案切換及清單往返中保留，切換工作空間後回到近 30 天／每日。

正式保存主任務由 active 類型變成 done 類型時記錄完成；直接建立於 done 也記錄。done 回到 active 記錄重新開啟，復原／重做亦依實際轉換留下紀錄。單純更名、換專案、封存、移入垃圾桶、還原垃圾桶或接收雲端版本不製造完成事件。子任務不加入這份主任務完成趨勢。

同一任務在同一個完成當地日期最多計一次，重新開啟不扣除已發生的完成；隔天再完成可計入新的一天。每週加總每日完成數，因此同一任務跨日完成可能計多次。先對整個工作空間依任務與日期去重，再按當天第一次完成時的專案篩選，避免同日換專案重複計數。紀錄保存發生當地日期，跨時區檢視不重新搬動日期。

完成紀錄保存當時的任務名稱與專案快照。後續改名、換專案、封存、刪除任務或移除專案，不改寫過去的統計；「包含封存任務與專案」只控制目前任務概況，歷史趨勢仍包含當時已完成的資料。完成日期從開始記錄之後累積，既有已完成任務不以修改日期倒推；第一筆紀錄之前不補零。尚無歷史時顯示說明，不繪製虛構數據。

點選非零資料點會開啟該日或該週的完成清單，支援鍵盤操作與每頁 30 項。滑鼠停留或鍵盤聚焦時顯示該點數量；橫軸以該日／該週起始日期標示，完整日期範圍及數量另提供文字提示。清單使用歷史名稱及專案；仍存在且未在垃圾桶的任務可按「開啟任務」，編輯後返回原日期清單。已移除或在垃圾桶的項目保留歷史文字，不開啟失效任務。

### 任務分類的計算與操作

每個主任務只計入所屬分類一次，子任務不另外加入分類分母。分類占比為該分類任務數／目前範圍的主任務數；分類完成率為該分類已完成數／該分類任務數，兩者分母不同。封存任務於開啟包含封存後加入分類總數，獨立列出，不算待完成。垃圾桶始終排除，封存專案也沿用總覽範圍。

分類依工作空間的順序、名稱與顏色呈現，最後列「未分類」。零任務分類保留文字入口、顯示 0% 而不畫扇形；相同名稱的分類仍依各自識別碼分開計算。分類文字先顯示 12 項，可按「顯示更多分類」逐批展開；圓環始終包含範圍內所有分類。

點選分類區塊或文字列會開啟該分類的清單彈窗，與目前專案及封存範圍取交集；清單可分頁與編輯，關閉編輯後返回原分類條件。正式儲存分類或狀態變更後，統計立即更新；分類改名或換色也會更新。已移除的分類顯示空清單，不改為查詢全部任務。「未分類」清單與其他分類一樣可於重新整理後接續，這些條件只保存為本機瀏覽偏好，不進備份或同步。

### 緊湊配置與參考

依使用者提供的兩張儀表板圖片，採用集中摘要與卡片分組的配置。數字摘要縮短、減少重複的查看文字與說明；寬桌面將完成比例、狀態分布與時程並列，較寬的專案圖與需要處理項目排在下方。卡片依內容高度排列，縮小圖表與內外間距；窄畫面依序改為兩欄、單欄，保留大字級與觸控操作空間。

## 時程與需要處理

時程重點顯示今日開始、本週開始、設定天數內到期及逾期。開始統計只看任務實際開始日期，不將跨週持續任務當成本週新開始；週區間為週日到週六。日期、時間與逾期沿用既有工具，以目前瀏覽器的當地時間計算；日期更新時重新衍生統計。

衝突任務每個衝突算一項，不把候選版本加入主任務分母。任一候選符合目前範圍即可列出；即使某份內容為刪除、目前沒有主任務，也能開啟原有比較與編輯流程。已解決衝突不列入。

連結狀態僅讀取共用查驗快取，顯示近期已查驗／範圍內獨立 Drive 來源數，以及可能無法存取或已在垃圾桶的數量。只有尚未過期的明確 unavailable／trashed 結果列為待處理；未查驗、過期、離線、待授權、配額或其他錯誤均不當作失效。有另一個可用來源時沿用共用服務的成功結果，不自行推斷刪除。Gmail 與未提供查驗的服務不加入 Drive 查驗分母。

總覽不主動查驗、不掃描 Drive 或讀取檔案內容。開啟任務後仍沿用該編輯器原有的可見連結查驗；快取清除或重新載入後，查驗覆蓋可能回到零，不表示連結已失效。

## 點選、編輯與關閉

點概況數字、圓環區塊、圖例、專案或時程項目後，在儀表板上方開啟任務清單彈窗，每頁最多 30 項。背景保留圖表、篩選與捲動位置；清單標示工作空間、專案及封存範圍。可按右上角 ×、「關閉清單」、Esc 或短按外圍遮罩關閉，焦點回到原本的統計入口，不再需要按返回。

清單內點任務開啟同一個任務編輯器，衝突入口開啟既有版本比較；一次只呈現一個可操作對話框。關閉或完成編輯後回到原清單，保留條件、頁碼與捲動位置；正式儲存後清單與背景圖表立即更新，本機草稿尚未套用時不改統計。任務編輯的 Esc／遮罩保護、× 暫存草稿及取消捨棄規則不變。原工作空間或資料世代已變更時，不重新開啟舊清單。

專案列先顯示 12 項，可逐批展開；大量任務不一次建立全部清單 DOM。總覽新增任務採用自己的專案，不繼承其他清單的分類或搜尋條件。

是否開啟總覽、專案、封存選擇及清單條件，按工作空間保存於既有本機瀏覽偏好。重新整理可接續條件，清單從第一頁開始；頁碼與捲動位置僅保留於這次編輯往返。關閉清單會清除當次下鑽條件。新工作空間在總覽模式下切換時顯示自己的資料，資料世代變更不接續舊條件。偏好與衍生統計不進正式工作資料或備份、不產生同步修訂；完成事件本身屬正式工作資料。

## 完成紀錄的儲存、備份與同步

首次產生完成或重新開啟事件時，至少使用看板格式 7、JSON／Drive 格式 8；已含相關任務連結的資料維持看板 8／備份 9，不降版。任務狀態與事件在同一筆本機交易保存；失敗時不留下半份資料，可沿用既有重新儲存流程。事件逐筆保存在 IndexedDB，完整 JSON、選定工作空間備份及 Drive 分塊備份皆包含歷史。匯入既有資料不額外產生完成紀錄；複製工作空間時重新配置任務、專案與事件識別，保留原日期和名稱快照。

雲端三方整併按事件識別聯集保留各分支的歷史，不因其他分支未帶舊紀錄而移除已知事件；同識別卻內容不同時拒絕靜默覆蓋。舊備份格式 1～7 仍可讀取，但無紀錄的舊任務不回填歷史。各裝置須支援實際使用的格式 8 或 9，不能將新資料降版並丟棄歷史。[相關任務與格式 9](related-tasks.md)。

## 驗證邊界

本機測試包含自訂狀態、兩種封存、垃圾桶、0%／38% 分母、未排程與單端日期、全天／指定時間／週邊界、重複關聯、查驗覆蓋與過期、刪除候選衝突、獨立偏好及清單分頁。10,000 項合成任務統計與共用來源去重用於確認資料處理，不代表整體瀏覽器效能承諾。

獨立完整 Angular App 與真正 IndexedDB 驗證下鑽、正式保存後統計、空空間、重新載入、鍵盤、手機大字級及深淺主題。Google 查驗使用合成回覆；未操作使用者原任務或真實 Google 服務。實體手機與真實跨裝置仍待驗收，詳見 [QA 紀錄](../QA.md)。

完成歷史另涵蓋同日去重、跨日／跨年及週邊界、歷史專案、改名與刪除、復原／重做、匯入／副本、並行事件聯集及舊分支、格式 8／區塊往返與損壞拒絕。原生 IndexedDB 檢查狀態與事件的交易原子性、並行保存、容量失敗和重試；介面以隔離合成資料確認每日／每週切換、清單往返、窄容器及大字級／深色主題，未以實體手機或真實 Google 跨裝置驗收。
