# IIH Orbit 使用指南

[文件索引](README.md) · [專案首頁](../README.md)

## 第一次使用

沒有已保存或可升級的資料時，Orbit 先提供一個暫時的空白工作空間，沒有任務、分類或專案。七步操作引導介紹工作空間、專案與任務分類、任務與狀態、五種視圖、Google Calendar、Gmail，以及本機備份與 Drive 同步；可略過，關閉或按 Escape 也會進入下一步。

完成或略過後，命名並選擇空白或樣板，建立第一個工作空間。選空白時，任務、分類與專案皆空；樣板的示範任務預設不勾選。建立成功會取代暫時空間，因此只留下自己建立的那一個。也可按「稍後建立」，之後由畫面提示返回；重新整理會接續工作空間選擇，不重播已完成的引導。

首次使用紀錄只存在目前瀏覽器，不進備份。已有資料、匯入或重置都不自動重播，也不清除既有內容。右上角問號可隨時重看介紹；結束後回到原本視圖與側欄，不新增資料或接續建立工作空間。

## 安裝到手機主畫面

以手機瀏覽 [正式站台](https://chiyang.github.io/iih-orbit/)，從瀏覽器選單選擇「安裝」或「加入主畫面」。Android Chrome 若提供安裝與建立捷徑兩種選項，請選安裝；iPhone 使用 Safari 的分享選單，選「加入主畫面」，若顯示「作為網頁 App 開啟」，請保持開啟。

從主畫面的 IIh Orbit 圖示開啟後，支援此功能的瀏覽器會以獨立視窗顯示，不帶網址列；手機系統狀態列仍可能顯示。網站需連線載入，這個版本未加入離線快取。安裝選項與名稱依瀏覽器版本而異。

## 工作空間與樣板

點側欄的工作空間名稱切換；右上角鉛筆可建立、改名或刪除。每個空間獨立保存專案、任務、分類、狀態與任務順序。工作區標題旁也可改名。刪除須輸入空間名稱確認，至少保留一個空間。

建立後續工作空間會有同名預設專案；第一次選擇空白工作空間則不加入專案。六種樣板皆可自行修改：

| 樣板 | 適用情境 |
| --- | --- |
| 學程行政 | 公文、會議與行政安排 |
| 學生事務 | 招生、活動與學生服務 |
| 課程安排 | 課程準備與教學工作 |
| 研究計劃 | 研究流程與成果整理 |
| 軟體開發 | 需求、開發與測試 |
| 學習進度 | 學習計畫與練習 |

每種樣板提供四個分類、額外一至兩個專案，以及可選的五個虛構示範任務。勾選「加入本週示範任務」才加入示範，日期依本機當週的週日至週六安排，包含全天、指定時間、多日、子任務及不同完成狀態。第一次建立預設不勾選；之後新增樣板工作空間可在表單勾選或取消示範任務。樣板只套用至新空間，既有內容保留。

## 專案與進度

主要導覽依序為「專案看板」「空間總覽」「待完成任務」「已完成任務」「封存任務」。點選「專案看板」、側欄 Logo 或手機頂端 Logo，會直接顯示目前工作空間的所有專案看板，清除當次搜尋、分類、專案、優先順序、釘選、最近編輯及日期篩選；總覽自己的專案與封存設定保留。沒有瀏覽紀錄時預設開啟看板，重新整理則接續目前畫面與瀏覽條件。

同一工作空間的專案共用看板、分類及狀態；每個任務可指定一個專案，或留為「未指定專案」。

「新增專案」開啟管理視窗，可新增、改名、封存、還原或移除。封存專案保留任務及個別進度，但不計入所有專案的完成數、總數與百分比；移除專案只清除任務歸屬，不刪除任務。過期操作會被阻止，避免蓋掉其他分頁的修改。

進度區預設為「所有專案」，箭頭可展開各專案任務數、完成數與進度條。選擇專案同步篩選五種視圖，新增任務預填該專案；所有專案下新增則優先指定同名或第一個未封存專案。整體進度排除已封存專案與封存任務，包含未指定任務，不受搜尋或分類篩選影響，也不是各專案百分比的簡單平均。

工作空間標題最右側的箭頭可縮小或展開資訊區，與「新增專案」「新增任務」按鈕等高。縮小後只保留工作空間名稱與這三個按鈕的一排；進度篩選與回報暫時隱藏，原本的篩選仍有效。各工作空間分別保存這個模式，包含在全部或選定工作空間的備份中；啟用遠端同步後可隨該工作空間同步。舊本機精簡模式會自動升級，已有同步設定時以工作空間資料為準。

## 空間總覽

左側「空間總覽」顯示目前工作空間的有效任務、待完成、已完成、逾期、未排程及有資訊連結的任務數，並提供完成率、自訂狀態分布、專案概況、今日／本週開始與即將截止。子任務另計，完成率為已完成／範圍內主任務；沒有任務為 0%。

完成比例與狀態分布以圓環圖呈現，時程使用任務數長條圖，專案使用已完成／待完成／封存的堆疊比例圖；仍保留數字與圖例。點圖形或圖例即可查看對應任務，圓環區塊也可用 Tab、Enter 或空白鍵操作。

總覽有自己的專案與封存範圍，預設排除垃圾桶、封存任務與封存專案，不受其他清單原先的已完成、分類或搜尋影響。點數字、圖表、狀態或專案會開啟對應清單彈窗，背景儀表板保留原位置；按 × 或「關閉清單」即可繼續查看圖表。清單內點任務開啟編輯，關閉編輯後回到原頁碼與捲動位置；正式儲存後統計更新。

「任務分類」用圓環呈現各分類及未分類的任務占比，旁邊列出總數、已完成、待完成與完成率；包含封存時另列封存數。沿用分類名稱、配色及順序，零任務分類仍可查看；點選圖形或分類列開啟該分類清單彈窗，並保留目前專案與封存範圍。

需要處理區列出目前範圍的衝突，以及近期已查驗且可能無法存取或在垃圾桶的 Drive 連結，附查驗覆蓋。未查驗不當作失效，總覽不自行掃描 Drive。總覽範圍與下鑽條件只保存在此瀏覽器，可於重新整理後接續。[完整計算規則](workspace-overview.md)。

## 任務、分類與狀態

任務可設定名稱、描述、專案、分類、狀態、優先順序、開始／截止日期時間與子任務。

- 預設狀態為待辦事項、進行中、待審核、已完成、封存。可自訂名稱、說明、顏色、順序與顯示；刪除狀態須指定任務移至哪個保留狀態，至少保留一個。
- 「一般任務」「已完成」「封存」類型決定進度與篩選，改名不影響語意。封存不列入完成比例、待完成數、逾期或月曆，改回其他類型即可恢復。
- 封存欄預設隱藏。「看板顯示」只影響專案看板，任務仍可在對應檢視找到；全部欄位隱藏時仍有管理入口。
- 分類可改名、排序、選擇快捷色票或輸入六位 HEX 顏色。分類順序同步到導覽、篩選與任務選單；刪除分類保留任務，改為未分類。
- 子任務可勾選並顯示進度。搜尋、分類、優先順序與待完成／已完成／封存檢視可組合使用。

### 垃圾桶與還原

刪除任務時先移至左側固定的「垃圾桶」，保留內容、子任務、釘選、時程與原本的任務順序。垃圾桶內的任務不出現在一般視圖、進度、提醒、釘選及最近編輯列表，但會包含在備份與同步中。點「還原」可回到原位置；如果期間移除了所屬分類、專案或狀態，會沿用該管理操作調整後的歸屬。

每個垃圾桶任務都有「徹底刪除」按鈕。確認視窗會顯示任務名稱及工作空間，按「確認徹底刪除」才移除該任務與子任務，其他任務及連結的雲端原檔保留。若任務已更新、還原、移除或仍有同步衝突，會阻止刪除，請重新查看或先處理衝突；保存失敗時任務仍保留在垃圾桶，可稍後重試。徹底刪除無法復原，並會清除該工作空間的復原與重做紀錄。

「清空垃圾桶」只清除目前工作空間的垃圾桶內容，確認視窗會顯示空間名稱及任務數量。清空後無法用復原找回；清空前若其他分頁修改了垃圾桶，會阻止過期操作。

### 復原與重做

視圖右上角與垃圾桶內都有「復原」「重做」按鈕。Ctrl／⌘ + Z 可復原，Ctrl／⌘ + Shift + Z 或 Ctrl + Y 可重做，涵蓋目前分頁的任務新增、編輯、改期、移動、排序、釘選、移至垃圾桶及還原，也涵蓋專案、分類與狀態管理。最多保留最近 50 步，各工作空間分開操作；輸入欄位中的快捷鍵仍使用文字編輯器本身的復原與重做。

復原後做新的修改，會清除該工作空間原本的重做路徑；失敗或未改變資料的操作不會清除。重新整理會清除操作紀錄。其他分頁已更新同一工作空間的工作內容時，會停用舊操作以保護最新資料。工作空間新增／刪除／改名、縮放模式、設定、Google 操作、匯入、重置、單筆徹底刪除及清空垃圾桶不列入操作紀錄；全部還原或重置會清除紀錄，單筆徹底刪除與清空垃圾桶會清除該工作空間的復原與重做紀錄。

### Markdown 描述

新任務預設編輯模式，既有任務預設預覽；可切換，支援標題、粗體、清單、勾選、表格與可點擊的連結。純文字換行及一般網址仍可閱讀，舊描述不轉寫。

在描述預覽上點兩下，或聚焦預覽後按 Enter，會切換到編輯並聚焦文字欄位。直接點連結仍會開啟連結。

描述文字區預設加高，仍可向下拉長。「專注編輯」會收起其他欄位，提供更大的空間；按「完成描述編輯」或「返回完整任務」返回表單。Tab 插入縮排，Shift+Tab 取消縮排；先按 Esc 再按 Tab 可離開描述欄位。Esc 不會關閉任務或離開專注模式。描述上限 20,000 字元；Gmail 自動帶入的描述仍維持精簡的 2,000 字元。

停止修改約 1.2 秒後會自動暫存本機草稿，不更新正式任務或觸發同步；按「儲存變更／建立任務」才生效。重新整理或關閉後再開相同任務，可選「恢復草稿」；按「取消」會捨棄這次編輯。草稿只留在此瀏覽器，不隨備份或同步移動，清除網站資料或同步登出會移除。詳見 [本機草稿與並行修改](task-editor-information.md#描述編輯與本機草稿)。

## 五種視圖

| 視圖 | 主要操作 |
| --- | --- |
| 看板 | 卡片跨欄拖曳改狀態，同欄可排序；觸控支援長按 |
| 清單 | 表頭排序、欄位原位編輯、狀態下拉修改 |
| 月曆 | 每日安排、跨日任務、點日期空白處進入該週 |
| 週視圖 | 全天橫條、可設定的時間範圍（預設 08:00–19:00）、點空白時段建立一小時任務 |
| 甘特 | 日／週／月時間軸、單一日期標記、未排程區；點名稱或時間條編輯，拖入郵件／檔案建立任務或加入資訊連結 |

手機看板可從卡片上直接左右滑動切換欄位，也可上下捲動頁面。需要移動任務時，先長按約 0.35 秒再拖曳；輕點卡片仍會開啟任務。

### 清單

名稱、專案、分類、優先順序及開始／截止日期可原位編輯，用儲存／取消確認。列上空白處或聚焦後按 Enter 開啟完整任務；操作欄位不會誤開明細。編輯期間若另一分頁更新、刪除或重置，會阻止覆蓋並保留草稿。

表頭可切換升冪／降冪，日期排序包含時間，未設定日期排最後。還原看板順序不改動已保存的任務順序。

### 甘特視圖

已排程任務按專案分區，左側固定顯示名稱、狀態與分類，右側可水平捲動時間軸；未排程集中在最後。「前往」可跳到指定區段。每區先已完成再未完成，各自按開始或截止時間由早到晚排序，並可篩選全部／已完成／未完成。

可切換日／週／月尺度，週細分每天、月細分實際每週；＋／− 與滑桿支援 50–250% 縮放。用「今日」、定位日期或箭頭移動。每列的背景固定使用任務狀態色，今天以前較實、今天起較淡；任務條固定使用分類色的淺底與深色邊框，文字保持清楚。時間條含起訖日；僅一端日期用菱形及「僅開始／僅截止」標示。

點名稱、時間條或「設定時程」開啟原任務編輯器，原日期時間保留；按儲存才更新。首版未提供拖移或伸縮。沿用目前篩選，甘特的日期、尺度、縮放、篩選、排序及已套用範圍按空間保存於本機。[完整操作與驗收邊界](gantt.md)。

填入範圍開始與結束日期後按「套用範圍」，僅顯示與範圍重疊的任務及日期軸，跨界部分裁切但不改任務。未排程暫時隱藏；按「清除範圍」恢復。欄位未套用或日期有誤時，原圖保持不變。

### 月曆與週視圖

月曆的「展開全部／收合全部」會記住目前瀏覽器中各工作空間的選擇，切換到其他視圖或重新整理後仍可接續，不加入 JSON／Drive 備份或跨裝置同步。全部展開後若單獨收合某天，就會退出全部展開模式；個別日期的展開只保留當次瀏覽。

週日開始，提供上一期、下一期與「今天」。日期旁的 ＋ 預填日期，點任務可編輯。月視圖移入日期格會以較淡底色標示整週；點空白處或日期數字開啟該週並標示所選日期。週視圖「今天」旁的「月曆」返回所選日期所在月份。

跨日任務顯示於開始至截止的每一天；只填一個日期則顯示於該日，皆空白列於未排程。月曆每天先顯示四項，可逐日展開或「展開全部／全部收合」。同日依全天 Google、全天 Orbit、時間 Google、時間 Orbit 排列；時間項目按開始時刻、標題排序，只有全天項目保留底色。

月曆與週視圖的「寬度」只在目前可用空間不足以容納七個寬版日期欄時顯示，可切換「標準／寬版」；空間足夠時自動隱藏，開關側欄或調整字級時也會重新判斷。標準沿用原本較緊湊的寬度，寬版的每日欄位至少寬 220px（隨字級縮放），空間不足時可在視圖內左右捲動；預設寬版，兩種視圖共用選擇，只保存在目前瀏覽器，重新整理可接續，不備份或跨裝置同步。工作區較窄時，月曆時間只顯示開始時刻；只有截止時間的任務顯示截止時刻。完整日期與起訖時間仍可由卡片提示或開啟明細查看。

週視圖每半小時一格，今天與目前時間有標示；日期／全天區垂直固定，時間軸水平固定。完整覆蓋一天的區段合併成全天橫條，首末日不足一天的部分留在時間格，重疊時段並排。例：週三 22:00 至週六 10:00，週四與週五是全天橫條，週三顯示 22:00–24:00，週六顯示 00:00–10:00；午夜截止不多顯示一天。單一開始／截止時間以標記呈現，短任務有最小高度。

時間表預設 08:00–19:00，可在「設定 → 外觀與閱讀 → 週視圖時間範圍」調整起訖小時，只保存在目前瀏覽器，不備份或跨裝置同步。部分超出範圍的卡片只裁切顯示，完整時程保留；完全在範圍外的安排列於「時段外安排」，可直接開啟，或按「顯示全天時段」暫時查看 00:00–24:00。再次按「使用設定時段」返回原範圍，全天安排不受此範圍限制。

點空白時段預填一小時任務，深夜自動換日；時間格可用方向鍵移動，再按 Enter 建立。日期列與全天區的滾輪捲動外層頁面，時間格捲動時間軸，到頂／底可接續捲動頁面；橫向滾動及觸控板縮放保留。

### 拖曳改期

本機任務在月曆平移整段日期並保留時間；週時間格依抓取位置以 15 分鐘定位，保留原跨度，跨午夜自動換日。時間卡片拖至全天區移除時間；全天跨日橫條平移保留首末日時段。單日全天轉時段預設一小時，多日保留日數；未排程拖入後設定截止標記。

拖曳有目的位置與邊緣捲動提示，保存前檢查跨分頁更新、刪除或重置。Google 活動維持唯讀，不可拖曳改期。

## 日期與時間設定

開始與截止各自可「加入時間」，截止不可早於開始。時間選擇器以 10 分鐘為主要選項，既有的其他分鐘值保留到自行調整。第一次加入另一端時間時，預設開始後一小時或截止前一小時；跨午夜調整日期，已輸入值不覆寫。

點日期欄開啟瀏覽器日期選擇器，時間欄整個按鈕均可展開小時／分鐘選擇。日期依本機時區解讀；沒填截止時間以當日結束判斷逾期，開始日期沒填時間則視為當日開始。

## 頁首、側欄與閱讀設定

頁首依序為到期時才出現的 G、已連結 Drive 時的即時同步、問號、主題、Aa 字體、設定及多功能右側欄開關。即時同步、設定與側欄都只顯示圖示；工作區變窄時隱藏主題與字體，保留同步及需要處理的授權入口。Gmail 與訊息提醒合併到最右側按鈕，依「衝突任務 → 訊息提醒 → 新郵件」優先顯示對應圖示及紅色數字，超過 99 顯示 99+；點擊直接開啟對應內容，提醒預先選擇有內容的日期範圍，新郵件預先顯示收件匣。當前內容已開啟時，點擊收合側欄；Gmail 有新通知時改為查看這批通知並保留側欄。沒有通知時維持原側欄圖示並接續上次分頁。欄內可切換任務／Gmail／檔案／訊息提醒，桌面可調整寬度，手機使用抽屜。

桌面右側欄可拖曳左邊界調整寬度，最窄 300px，一般畫面上限 800px；當畫面寬度的 45% 超過 800px 時，上限改為 45%（例如 2560px 畫面可達 1152px）。邊界聚焦後可按左右鍵微調。實際上限仍保留主畫面操作空間，必要時左側導覽會收進選單。選定的寬度保存在本機；視窗縮小時暫時收窄，放大後恢復，超過 800px 的寬度也能重新開啟接續。任務、Gmail、檔案與訊息提醒共用此寬度，手機維持抽屜顯示。

開啟 Gmail 側欄先顯示對應快取，距離上次成功更新滿五分鐘或沒有快取時才重新讀取；按「更新」可立即讀取。新郵件通知只在郵件列表成功更新後檢查，沒有每分鐘的獨立檢查。顯示這次開啟的郵件後，整批收起當前通知數字，「新郵件」標記保留至這次瀏覽結束，郵件內容及 Gmail 未讀狀態保留。側欄一直開著時，後續更新取得的新郵件仍會增加數字；逐封閱讀或更新列表不自動清除通知。可點頁首信封或欄內 Gmail 分頁查看下一批，此時標記改為這批新郵件。訊息提醒同樣以「新提醒」標示這次瀏覽的新項目，切換提醒範圍或開啟明細時保留標記。通知查看紀錄只保存在目前瀏覽器，重新整理可接續。衝突使用三角形圖示與數字，直到逐項解決衝突，不另加新項目標記。

郵件預覽在寬度至少 1280px 的畫面會放大至畫面寬度的 92%（最高 1800px），高度隨視窗延伸並保留上下邊距。信件內文靠左對齊，討論串清單與信件內文各自捲動；較小畫面維持原本的預覽尺寸限制。

Gmail 篩選標籤需按「儲存並套用」才生效，「取消變更」恢復原選擇。已套用標籤只在目前瀏覽器保存，不進 JSON／Drive 備份或跨裝置同步；更換裝置後須重新選取。這不影響任務與郵件資訊連結的備份。[標籤與快取規則](gmail-design.md#設定與標籤)。

郵件列表中的「相關任務（N）」按單封郵件計算，展開可查看任務與工作空間並開啟編輯；討論串回覆各自計數，垃圾桶任務不列入。從郵件拖放或按鈕建立任務，都會保存原信資訊連結。甘特也支援拖到任務名稱／時間條加入連結，或拖到空白時間軸建立任務。[甘特拖放操作](gantt.md#從郵件與檔案拖放)。

頁首移除本機自動儲存與遠端自動同步備份的文字按鈕；資料與備份及遠端同步都可從設定管理。本機仍自動保存，儲存失敗仍會在工作區顯示提示。離線前可按同步圖示，等待「同步已完成」；處理中按鈕停用並轉圈，授權或內容須處理時有紅點。同步期間又新增修改時會提示再次同步。

設定分頁包含外觀與閱讀、任務提醒、Google 連線、Google 月曆、Gmail、Google Drive、遠端同步備份、資料與備份及資料重置；可用方向鍵、Home／End 切換，同一視窗內未送出的設定草稿保留。設定標題、分頁及完成按鈕保持可見，內容獨立捲動。對話框支援焦點管理及減少動態效果；一般視窗可用 Escape 關閉，任務編輯保留開啟。

任務編輯視窗點擊外側遮罩不會關閉，請用右上角 × 或「取消」關閉；× 保留本機草稿，「取消」捨棄這次編輯。其他對話框的外側遮罩必須在同一處按下並放開才會關閉；從內容拖到外側選取文字不會誤關。

主題按鈕依淺色、深色、跟隨系統循環。字體有 70%、80%、90%、100%、115%、130%，各視圖、表單及主要內距／欄距同步縮放；小字級更緊密，側欄仍保留最低可用寬度。主題色提供綠、藍、紫、橙及六位 HEX 自訂，文字／標籤依背景調整對比；閱讀偏好重新整理及同來源其他分頁可接續。

深淺色／跟隨系統與字體大小依各裝置的喜好、系統設定及螢幕自行選擇，只保存在目前瀏覽器，不包含在備份或遠端同步中。還原、接續雲端內容及同步更新皆保留本機主題與字級，含這些設定的舊備份也不會改變目前選擇；「重置整個 Orbit」仍會重設本機外觀。主題色維持原本的備份與同步規則。

品牌正式名稱為 TMU IIh Orbit，標語為「讓每一步都慢慢上軌道」。橢圓軌道圍繞中央 IIh，配合主題色及字級調整；工作空間識別使用名稱第一個完整字元，支援中文、英文與表情符號。側欄介紹標題為「任務導向的文件連結空間站」，保留圖示與單行文字，底部標示「單人工作空間站」，並提供 GitHub 連結。

## 衝突任務、釘選與最近編輯

跨裝置同步會自動整併不同任務或欄位的修改。無法自動決定的任務列在右側欄「任務 → 衝突任務」，沒有衝突時隱藏該區塊；右上側欄按鈕顯示待處理數量。清單包含所有工作空間，按「比較與編輯」或點選有衝突的任務，即可開啟各份完整任務。桌面並排比較，窄螢幕上下排列；描述保留原文，使用者可修改其中一份的所有任務欄位後，按「儲存並採用這份」，也可直接採用未修改的版本。儲存與選擇可一起復原或重做，原選項留在已處理紀錄。待選版本會一起備份與同步，其他任務仍可繼續使用；啟用同步並連線後，其他裝置會接收選擇結果。設定或結構上的分歧仍在「設定 → 遠端同步備份」處理，詳見 [自動整併](backup-and-sync.md#自動整併與衝突任務)。

版本上方顯示最近內容編輯來源與修改時間。在「設定 → 資料與備份」填寫「這個裝置的名稱」，例如工作電腦、我的 iPhone；名稱只保存在目前瀏覽器，後續編輯會附上來源，不會補寫舊版本。未記錄的來源或時間會明確標示。編輯期間若版本更新，草稿仍保留，須重新查看後再儲存。

任務卡片與清單第一欄提供圖釘按鈕，未釘選為空心、已釘選為實心，可即時釘選或取消；任務表單的圖釘位於名稱輸入框左側，隨儲存變更一起保存，取消編輯保留原釘選狀態。任務建立／編輯視窗使用單行精簡標頭，保留更多內容空間。右側欄的「任務」分頁列出目前工作空間所有專案的釘選任務，以及最新 20 筆最近編輯，包含已完成與封存任務並標示狀態。點任務可直接開啟最新內容，原主畫面篩選保留。

右側列表中已釘選的任務只顯示圖釘標記，沒有直接取消按鈕，避免誤觸；需要取消時可開啟任務表單，或使用主畫面的卡片／清單按鈕。最近編輯列表中的未釘選任務仍可直接加入釘選。

分類與日期同一排新增「釘選任務」與「最近 7 天編輯」toggle，再按一次可取消；兩者可同時啟用，並與搜尋、專案、分類、日期、優先順序及任務狀態取交集，連動看板、清單、月曆、週視圖與甘特。「最近 7 天」包含今天，以本機日期計算。月曆篩選時暫時隱藏 Google 活動，清除後恢復原來源選擇。

工作區變窄時，搜尋仍直接顯示，分類、日期、優先順序、釘選、最近編輯與提醒快捷按鈕收進「進階篩選」展開區塊。按鈕顯示已套用的篩選條件數；收合不清除條件，畫面下方仍保留篩選摘要與清除按鈕。此排版依主畫面可用寬度調整，開啟右側欄時也適用。

建立、儲存內容、調整時程、修改子任務或改變狀態會更新編輯時間；單純釘選、同欄排序、開啟或未改動儲存不更新時間。舊任務未保存編輯時間，從下一次實際修改開始記錄。釘選與編輯時間跟隨任務進入備份與同步；側欄開關與 toggle 選擇屬於本機瀏覽偏好，重新整理會還原。

## 瀏覽狀態與訊息提醒

重新整理會還原當前視圖、月曆日期、週時間軸位置、搜尋篩選、排序、Google／Orbit 顯示選擇及右側欄。各工作空間分別保留瀏覽選擇；切換空間保留側欄，新空間沿用目前視圖與日期。這些選擇只存在本機，不進備份；重置或全部還原後回到預設。

「已逾期」及 1／3／7／30 天內到期篩選排除已完成、封存與沒有截止日期的任務；清單預設依截止時刻排序。到期範圍預設三天，可在任務提醒設定為 1–30 天。截止篩選期間暫時隱藏 Google 活動，清除後恢復。

日期下拉選單的「未設置」只依截止日期是否空白篩選，因此只有開始日期的任務也會列入。沿用目前的任務狀態、搜尋、專案、分類與優先順序條件，清單預設保留看板順序；重新整理保留選擇。

「本週任務」以目前日期所在的週日至週六為範圍，包含排程與本週重疊的待完成任務：只有開始日期、只有截止日期或跨週安排皆可列入，排除完成、封存及未排程任務。主畫面的快捷按鈕與日期下拉選單套用到各視圖，清單預設依開始日期排序，只有截止日期的任務排在後面；月曆篩選時暫時隱藏 Google 活動。重新整理保留篩選，跨入週日後自動改看新的一週。

訊息提醒整理今日開始、明天開始、本週任務、下週開始、即將到期與已逾期。本週及開始列表包含工作空間內顯示的 Google 活動；僅有截止日期可列入本週，但不列為開始。頁首鈴鐺只計算尚未查看的新提醒，同一任務／活動去重；在前景開啟提醒側欄後收起現有徽章，清單仍保留。新增、改期或進入今日／逾期狀態會再提示，修改標題不重新提示；沒有新提醒時不再讓鈴鐺長駐，仍可由側欄分頁查看全部清單。查看紀錄只在目前瀏覽器保存，可接續同來源分頁及重新整理，不進備份或跨裝置同步。可按來源或月曆篩選，點項目開啟明細後仍可繼續瀏覽側欄；重新整理保留選擇的提醒分頁。

前景提示預設提前 30 分鐘，全天安排預設 09:00，可在設定調整或關閉。只有程式開啟期間運作，關閉頁面不繼續提醒；郵件側欄開啟時不顯示右下角浮窗。完整規則見 [提醒設計](reminder-design.md)。

## 任務資訊連結

任務視窗在寬畫面使用雙欄，窄畫面或大字級自動改為單欄。資訊連結可填寫這個任務中的用途，並以拖曳或上下箭頭混合排序；新增項目附加末端。用途與順序都在儲存任務後生效，取消保留原內容，復原／重做也包含這些變更。[詳細操作與相容性](task-editor-information.md)。

Drive 連結會按需更新目前可見項目的名稱、類型、外開連結與位置，並標示可存取、授權到期、垃圾桶、可能刪除／權限變更或限流等狀態。可指定查驗來源並按「更新連結資訊」；一般開啟沿用有效快取，離線或失敗保留最後資訊。路徑不完整時明確提示部分位置。查驗不修改用途、順序或任務時間，也不自動解除失效連結。「設定 → Google Drive」提供過期／全部檔案快取清除及筆數回饋。[操作與查驗規則](document-information-refresh.md)。

按「建立文件」可選 Google 文件、試算表、簡報或 Colab 筆記本（Python），以及來源、名稱與保存位置。Colab 會建立空白 Python 筆記本、自動補上 .ipynb，完成後可直接用 Colab 開啟。新任務或修改中的草稿先由你按「儲存任務並繼續」；雲端建立及關聯成功後直接保存，可點 ↗ 開啟原文件。按「選擇 Drive 資料夾」直接使用已連線的 Google 授權載入列表，可逐層瀏覽、搜尋及選取；取消保留原位置，不需 API Key 或專案編號。選取只讀取資訊，按建立時才由 Google 取得所需寫入授權；手動連結入口保留在「更多選項」。逾時時先查核結果，文件已建立而任務未保存時只重新加入原檔，避免多建一份。「設定 → Google Drive」也可接續未完成建立及查看、整理完全沒有引用的來源；歷史事件與雲端原檔保留。[完整操作與限制](document-creation-and-cleanup.md)。

右側欄提供「檔案」分頁，直接以 Google Drive 列表 API 讀取目前資料夾。分頁列只有目前分頁顯示名稱，其他以圖示呈現；調整側欄寬度時，分頁列填滿關閉按鈕以外的可用寬度。點資料夾名稱或雙擊資料夾項目進入下一層，檔案名稱為文字；檔案與資料夾旁的 ↗ 會在瀏覽器新分頁開啟。使用麵包屑與返回上層導航，搜尋只查目前位置。尚未連線時可開啟 Google Drive 設定完成授權。

檔案與資料夾可拖到看板／清單的既有任務中央加入連結；拖到卡片邊緣或空隙則直接建立已連結的新任務。拖到月曆日期或週曆全天區建立全天任務，拖到週時間欄建立一小時的任務。月／週中的 Orbit 任務也可接收連結，Google 活動不可連結。

任務表單的「資訊連結」可「瀏覽 Drive 加入連結」或貼上 Drive 連結。瀏覽會開啟專用選檔視窗，可選取多份來源再確認；取消或 Escape 只關閉選檔，保留任務草稿。選檔與側欄共用授權，路徑、搜尋及選取各自獨立；新增／移除在儲存任務後生效。移除只解除 Orbit 關聯，雲端原檔保留。

檔案列表會以圖示辨識 Google 文件、試算表、簡報、Colab／ipynb、ECMX、PDF 與圖片；捷徑沿用目標類型，未知類型仍顯示一般檔案。選檔視窗可展開「相關任務（N）」查看任務名稱，這裡不跳轉；側欄仍可開啟相關任務。

資訊連結、任務時程與子任務使用一致的背景及外框。看板卡片與清單名稱下方會顯示有效資訊連結項數，包含 Gmail 與檔案／資料夾；無連結時隱藏。相同來源不重複計數，儲存新增或移除後更新，取消編輯保留原數量。

Gmail 郵件也可拖進看板／清單與月／週中的 Orbit 任務，加入資訊連結且保留原任務內容與時程。拖到卡片邊緣、空隙、日期或時段則建立已連結的新任務。郵件建立任務按鈕與預覽建立也帶入連結；原信仍保留。[完整操作與相容性](task-document-phase1.md)。
