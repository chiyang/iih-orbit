# 本機任務離線使用與 PWA 安裝

正式版本首次開啟時，需要先連線完成程式下載；離線程式會在背景準備，主畫面不顯示常駐狀態列。完整下載後，可以在同一瀏覽器及網站位址關閉再開，瀏覽與編輯本機任務；不需要先安裝到主畫面。第一次從未開過的裝置不能直接離線使用。

## 安裝到裝置

- 電腦 Chrome／Edge：開啟正式網站後，使用網址列的安裝圖示或瀏覽器選單中的安裝應用程式功能。
- Android Chrome：使用瀏覽器選單中的「安裝應用程式」或「加到主畫面」。
- iPhone／iPad Safari：使用分享選單中的「加入主畫面」，並在有提供選項時選擇以網頁 App 開啟。

選項名稱依瀏覽器版本而異。安裝後仍應先連線開啟，讓程式完成下載；各瀏覽器或安裝方式可能使用不同的資料儲存區，請確認原有任務已載入或接續雲端資料後，再離線操作。

安裝入口可參考 [Chrome 說明](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DDesktop&hl=zh-Hant)及 [iPhone Safari 說明](https://support.apple.com/zh-tw/guide/iphone/iphea86e5236/ios)。

## 離線使用範圍

- 新增、編輯、釘選、狀態與時程修改沿用既有 IndexedDB 本機儲存；正式保存與任務編輯草稿仍分開。
- 相關任務連結、甘特日期操作及完成歷史／折線趨勢使用本機工作資料，離線時也可操作或查看；不因此下載外部文件或郵件本文。
- 本機保存不表示已同步到雲端；保存失敗沿用既有警告，Drive 同步狀態仍由原有同步控制顯示。
- 主畫面不新增離線、保存或更新狀態列，保留任務顯示空間。裝置回報連線不保證 Google 或網站服務可達，外部服務錯誤仍由各服務顯示。
- 網路恢復後沿用 Drive 的既有排程、授權與衝突處理，不承諾關閉程式後仍能背景同步。授權到期需要重新授權。
- Google 文件、Gmail 與 Calendar 的遠端操作需要網路；本次未新增外部文件本文或郵件的離線下載。
- 新版本會在背景完整下載並驗證；儲存編輯並關閉所有 Orbit 分頁及獨立視窗後，重新開啟即可使用已備妥的版本。更新不強制重載現有編輯器。
- 清除網站資料會移除本機任務與離線程式；瀏覽器也可能回收網站儲存。重要資料仍應備份。

## 建置與快取範圍

`npm run build` 與 `npm run build:pages` 在 Angular 建置後產生 `sw.js`，包含所有輸出資源（含延後載入畫面）的 SHA-256 清單；不包含 source maps。版本識別同時包含資源與 Worker 程式，避免僅更新 Worker 時共用並誤刪使用中的快取。僅正式版本註冊 Service Worker，開發伺服器不準備離線程式。部署需使用 HTTPS（本機 localhost 測試例外），並完整發布建置輸出。

這是專案自訂的 Service Worker 與建置腳本，未使用 Angular 的 `@angular/service-worker` 或 `@angular/pwa` 套件。任務仍由原有 IndexedDB 保存，Service Worker 負責快取啟動所需程式。

安裝時逐個驗證資源，任一失敗會捨棄未完成的新快取，保留原版本。頁面與資源從同一版本快取讀取，避免離線時混入新版入口或缺少編輯畫面。快取名稱按網站 scope 隔離；更新只移除該 scope 的舊程式快取，不清除 IndexedDB、登入憑證或其他網站的快取。Google API、跨來源要求、未知資源與寫入要求不納入快取。

更新遵循瀏覽器的等待生命週期，不呼叫 `skipWaiting()`，等使用舊版的分頁關閉後才啟用。啟用完成前會接管尚未受控制的頁面，讓首次開啟的頁面在不重新整理的情況下，也能離線載入尚未開過的畫面。機制參考 [Service Worker 生命週期](https://web.dev/articles/service-worker-lifecycle)。

## 系統通知與程式開啟期間排程

系統開始通知使用獨立開關與權限，正式 PWA 優先透過 Service Worker 顯示及處理點擊；提醒排程仍由開啟中的程式執行。安裝與離線可開啟不表示關閉程式後仍會準時通知。本工具維持純前端、無後端，沒有背景 Push 訂閱或常駐計時服務。[啟用方式、保存規則與裝置限制](reminder-design.md#系統開始通知)。

## 驗證紀錄

- `npm run check`、正式 GitHub Pages 子路徑建置與完整單元測試。
- 6 項離線測試：完整資源與延後畫面、入口 query、混合版本失敗保留舊快取、作用域清理及遠端／寫入要求不攔截、可重現建置與僅更新 Worker 時的快取隔離，以及啟用完成前不宣告就緒、本機保存／未保存狀態與更新等待。
- 隔離瀏覽器以 `/iih-orbit/` 開啟正式輸出，等待離線準備；測試伺服器中斷所有一般要求後，首次開啟月曆成功，新增與修改任務成功；重新載入及關閉分頁後離線重開，名稱、描述與狀態仍存在。
- 初版模擬發布第二版：編輯中的草稿保留，另一分頁顯示新版等待提示；儲存後關閉編輯分頁，仍開啟的另一分頁重新整理仍使用舊版；關閉全部分頁後重開才使用新版，任務內容保留。其後依使用偏好移除主畫面的整列狀態資訊，背景更新機制保留。
- 移除狀態列後，重新檢查正式建置及 6 項離線測試；離線服務改由程式啟動時初始化。隔離測試站台停止後重新載入，任務仍可讀取，主畫面沒有狀態列或預留空間。
- 以上為本機服務中斷與版本發布模擬，並非實體裝置飛航模式、手機安裝流程或真實 Google Drive 同步驗收。
