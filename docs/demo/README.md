# README 示範素材

此資料夾保存 README 靜態展示使用的虛構工作資料。示範資料不會自動載入正式 App，也不更動首次啟動的空白工作空間。

## 同一組示範資料

- 工作空間：共創實驗室。
- 專案：秋日共創工作坊、課程網站改版、研究交流分享。
- 分類：企劃協作、設計製作、內容教材、研究分析。
- 任務：20 項；待辦、進行中、待審核、已完成各 5 項，完成率 25%。
- 時程：2026 年 10 月，包含跨日任務、定時活動、子任務、釘選及 2 組相關任務。

任務、描述、專案與內容全部為虛構；不含真實郵件、檔案、個人資料、Client ID 或授權憑證。

## 下載與匯入

下載 [orbit-demo.json](orbit-demo.json)，在 App 的「設定 → 資料與備份」選擇備份檔，預覽後按「新增 1 個工作空間」。這是工作空間備份，會新增獨立副本，保留原工作空間；不使用全部資料還原。

日期固定在 2026 年 10 月。匯入後可切到該月份；週視圖選擇 10 月 18–24 日，甘特選擇週尺度並定位 10 月 12 日。之後開啟時，「今天」、逾期標示及提醒數可能與截圖不同。

## 截圖設定

2026-10-19 於獨立本機來源 `http://127.0.0.1:4316/`，透過 App 原有匯入功能載入資料，再使用實際 UI 切換視圖拍攝。沒有改寫 UI 文字、插入假的 Google 連線狀態或修改正式站點資料。

- 桌面檢視區 1600 × 1100，讓四欄看板與七天日曆可完整並排。
- 淺色主題、預設綠色、標準 100% 字級；收合工作空間資訊，保留左側導覽。
- 所有專案、所有日期，不套用分類或優先度篩選，右側欄關閉。
- 月、週視圖採「標準」寬度；月視圖不展開全部活動。
- 月、週視圖拍攝整頁；看板與甘特拍攝檢視區，保留原有捲動行為。甘特為週尺度、100% 縮放、定位 2026-10-12。

## 重建資料

在專案根目錄執行：

```sh
node scripts/create-readme-demo.mjs
```

腳本使用 App 的 `createBackup()` 與 `readBackup()` 產生並驗證固定資料，只寫入此資料夾的 JSON，不讀寫瀏覽器儲存空間。重新執行不會自動重新拍攝截圖。

## 來源轉為任務操作圖

以可編輯 SVG 繪製三列操作流程，再匯出 PNG，供 README 的詳細操作連結查閱。此圖為靜態操作示意，所有郵件、檔名與活動內容皆為虛構。

- **Gmail**：郵件卡片 → 游標與半透明拖曳卡片 → 新建同主旨任務，帶有 Gmail 原信資訊連結。
- **Drive**：檔案卡片 → 拖到工作區空白落點 → 新建同檔名任務，帶有 Drive 檔案資訊連結。
- **Google Calendar**：活動明細 → 按「複製為 Orbit 任務」並確認 → 建立保留起迄時間的獨立任務。原活動仍保留，兩邊各自編輯；不畫成拖曳或自動來源關聯。
- **既有任務**：把 Gmail 郵件或 Drive 檔案拖到任務卡片中央，可加入資訊連結，保留任務內容與時程。

箭頭只表示來源轉為任務的操作流程，不代表任務相依、雙向同步或自動排程。對應現有行為見 [Gmail 拖放](../gmail-design.md#建立任務與資訊連結)、[Google Calendar 複製](../google-calendar.md#複製為-orbit-任務)及 [Drive 檔案來源](../drive-file-sources.md)。
