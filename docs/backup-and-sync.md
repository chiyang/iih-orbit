# 備份、還原與遠端同步

[文件索引](README.md) · [專案首頁](../README.md)

本機自動儲存保存目前瀏覽器的內容；JSON 備份便於搬移或還原；遠端同步備份則使用 Google Drive 接續其他裝置的資料。三者的保存位置不同。

## 本機 JSON 備份

開啟「設定 → 資料與備份」，可下載全部資料或選定工作空間。備份不需要 Google 帳號。

匯入先驗證格式，顯示工作空間數、任務數、日期與匯入方式，再確認套用：

- **全部還原**：取代現有全部資料與設定，提供先下載目前備份。成功後建立新的資料世代、暫停自動處理，須重新連線 Google；無法直接撤銷，請保留還原前備份。
- **加入工作空間**：建立獨立副本，重新產生工作空間、專案與任務等內部識別，保留目前資料與外觀。附帶公開 Google 設定須另勾選才套用。

格式不支援、資料驗證失敗或容量不足時保留原資料；必須成功保存才套用。備份格式為 `application: iih-orbit`；含連結用途／順序時為 `formatVersion: 7`，只有文件來源與關聯時為格式 6，未使用文件的資料仍為格式 5，支援匯入格式 1–6 的舊備份，單檔上限 20 MB。相容性及重置詳見 [資料儲存](data-storage.md)。

## 備份包含哪些內容

| 內容 | 全部資料備份 | 選定工作空間備份 |
| --- | --- | --- |
| 工作空間、專案（含封存）、任務、子任務、分類、狀態、顏色、順序及隱藏設定 | 全部保存 | 保存勾選的空間 |
| 文件來源、任務關聯及移除事件 | 全部保存 | 保存勾選空間的完整來源及關聯 |
| 任務待選版本及已選用的處理紀錄 | 全部保存 | 保存勾選空間的紀錄 |
| 主題色 | 保存 | 不包含 |
| 深淺色／跟隨系統 | 不包含，保留目前瀏覽器的選擇 | 不包含 |
| 字體大小 | 不包含，保留目前瀏覽器的選擇 | 不包含 |
| 到期天數、提醒提前時間、全天提醒時間、彈出及 Google 提醒開關 | 保存 | 不包含 |
| 公開 Client ID、Calendar／Drive 帳號識別、Calendar 更新頻率 | 保存 | Drive 的空間備份不包含；本機匯出可另外勾選公開 Google 設定 |
| 月曆來源名稱、顏色、顯示設定與工作空間綁定 | 保存 | 保存勾選空間的來源 |
| Drive 模式、範圍、修改後等待時間與檢查頻率 | 保存 | 不包含 |

不備份 Google Access Token、授權狀態、Calendar 活動快取、Gmail 帳號／預覽／標籤偏好、Drive 待上傳佇列與同步基準、已提醒紀錄、首次引導紀錄或瀏覽狀態。Google 原活動與郵件保留在 Google；已建立的 Orbit 任務完整保存。

## 連線 Drive：先接續已有資料

1. 依 [Google 連線設定](google-setup.md) 啟用 Google Drive API，保存 Client ID，再開啟「設定 → 遠端同步備份」連線 Google Drive。
2. 連線後先讀取「雲端資料」，同一清單列出目前使用的資料、其他電腦的資料及另存備份。
3. 有既有資料時，按「查看並使用」，核對工作空間、任務數及外觀，再按「使用這份雲端資料」接續自動保存。
4. 成功確認雲端沒有資料後，才顯示「建立第一份自動儲存」。固定保存全部工作空間與設定，並接收其他電腦的更新，不需要選範圍或方式。
5. 建立前會再檢查雲端；其他電腦已新增資料時，返回既有清單。有資料但確實需要獨立集合時，才使用「已有資料，但想另外建立一份？」。

兩台電腦需使用相同 Client ID 與 Drive 帳號。Drive 使用 `drive.file`，只列出 Orbit 建立或明確授權的資料；連線成功不代表自動保存已啟用。

清單讀取失敗時保留上次結果並標示，不能把失敗當成「沒有雲端資料」而建立新集合。已連線時開啟面板自動讀取一次，重新授權後再讀取；焦點或一般設定變更不重複讀取。可手動「重新載入」，並查看清單更新時間。

## 自動保存與跨裝置同步

自動儲存固定保存全部工作空間，並接收其他電腦的更新。建立與使用雲端資料不再提供範圍、方式選擇，也沒有「調整儲存範圍與方式」入口。舊版部分工作空間或單向備份會先同步原集合，再改為完整同步；部分集合另建立完整集合，保留原雲端資料與其他本機工作空間。

目前使用的雲端資料卡片展開「更多操作」，可調整修改後等待時間與雲端檢查頻率。修改後預設等待 15 秒，可改為 30／60 秒；雲端檢查預設每五分鐘，可改為一分鐘、十五分鐘或關閉輪詢。既有間隔偏好保留。關閉輪詢仍可手動處理及保存本機修改；仍可暫停及恢復自動儲存。

連續修改會從最後一次修改重新計時。本機仍在儲存或等待上述延遲時，定期檢查及回到前景的檢查會延後；按「立即同步」可在本機保存完成後直接執行。

程式開啟、授權有效且連線時才自動處理。離線修改先保存在本機，恢復網路／授權後再處理；沒有背景工作或自動延長授權。頁首不再顯示本機與遠端儲存的文字按鈕；已有 Drive 儲存連結時，顯示無文字的即時同步圖示，手機也保留。按下立即同步，處理期間停用並轉圈，完成後顯示確認提示與完成圖示，滑鼠提示包含最近完成時間。新的本機修改會清除完成圖示。

已有啟用的雲端儲存集合時，Drive 授權成功、續期或重新開啟頁面恢復憑證後，會等本機儲存與目前雲端作業結束，再立即核對並同步；這次同步不套用修改後的等待秒數。另一分頁正在同步時，會等候完成後再自動核對。首次尚未選擇集合、已暫停、雲端內容待選擇或登出資料尚未接回時，保留原本設定與資料，先完成對應步驟。

授權到期、雲端內容待選擇、暫停或儲存失敗等狀態會有紅點；連線或整份資料須處理時，點擊直接開啟遠端同步設定。正常上傳中的暫存版本不顯示紅點；結束後仍有待上傳資料時，提示會說明。任務衝突也顯示紅點，但不阻擋即時同步，各份內容一起保存，採用版本由右側欄處理；若已確認目前內容同步完成，勾選與任務衝突紅點可同時顯示。完成前會核對目前內容與雲端基準；同步尾聲又有新修改時，提示已排程自動同步，依最後一次修改的等待秒數接續。接收雲端資料產生的延後變更通知，不清除已核對同一修訂的完成圖示。離線前請等待完成提示；之後再編輯的內容仍需另一次同步。

跨裝置同步包含全部工作空間、專案、任務、分類、狀態，以及月曆來源名稱、顏色、顯示開關與綁定，另外同步主題色、提醒偏好及 Calendar 更新頻率。深淺色／跟隨系統與字體大小只保存在目前瀏覽器，新備份不包含這些偏好；匯入或接收舊備份也不會覆蓋本機選擇，單純調整主題或字級不建立新的雲端版本。舊雲端檔維持原始校驗，既有同步基準接續新比對規則，不改寫歷史檔案。

Client ID、Google／Drive 帳號與授權，以及 Drive 模式、範圍、保存與檢查頻率保留各裝置設定。**完整備份可以攜帶這些公開設定，但接收跨裝置同步不覆蓋它們。** 相同共享內容不重複上傳，接收後也不再回傳一次。

使用過去的完整備份會套用全部資料與設定、暫停自動處理並要求重新連線；「加入工作空間」保留目前資料與設定。預覽或確認期間本機內容、雲端版本或授權改變時，須重新確認。

## 同步並登出

已設定遠端同步時，頁首會顯示「同步並登出」按鈕。按下先開啟確認視窗；取消、Escape 或點擊遮罩均不備份、不清除資料，確認後才開始處理。處理中不能關閉視窗或重複確認。

確認後會先同步最新內容，沿用完整集合另存完整備份，再從 Drive 讀回驗證。舊部分範圍會先安全改為完整集合；暫停自動儲存也可以手動完成這次備份並登出。成功後才重置本機工作空間、任務、設定、瀏覽狀態、提醒紀錄、服務快取與 Google 憑證，只保留公開 Client ID 與集合識別，並回到原本未登入、沒有工作資料的預設介面，頁首保留 G 按鈕。離線、授權到期、上傳或驗證失敗、仍有雲端內容待選擇，或備份期間有新修改時都會停止登出，保留本機資料。清理遭瀏覽器阻擋時，在原介面顯示重試清理提示。

下次開啟按 G 授權，即會取回原集合並恢復自動同步。只有一份目前內容時直接接回；原集合有多份不同內容時列出選項，選定後套用。即使同帳號有其他集合，也不會誤接另一份；帳號不對、原集合已刪除或範圍已改變時會顯示原因並保持登出。

登出後仍可使用本機工作空間。若已新增或修改工作資料，G 登入會保留這些資料，提示先備份並在遠端同步設定預覽、選擇雲端內容。完成清理後重新開啟不再重複清理新偏好或服務連線。

## 分塊保存與傳輸

新的自動同步以版本索引引用共用區塊，未變內容不重複上傳。每份索引仍代表全部工作空間的完整資料，共同祖先整併及衝突流程維持原則；必要區塊保存並驗證完成才發布。舊完整 JSON 繼續讀取，手動 JSON 匯入／匯出及雲端獨立另存維持不變。新版索引不能單獨當作可攜 JSON 備份，請在 Orbit 下載完整資料。其他裝置需更新至可讀雲端格式 5 的版本；含文件資料使用格式 6，所有接續裝置也須支援格式 6。[文件關聯與相容性](task-document-phase1.md)。

本機按紀錄保存、區塊粒度、量測及限制見 [本機紀錄與雲端分塊備份](storage-sync-upgrade.md)。首次同步或大量修改仍可能較慢，目前沒有真實 Google Drive 的速度承諾。

## 最近八份與過去備份

每份自動備份／同步資料保留最近 **八份：最新一份＋過去七份**。有內容或設定修改並完成保存才建立新版本；匯出時間、程式版本或分頁選定空間不造成重複紀錄。

連線讀取及重新載入時可清理過舊版本；日常同步先完成保存及更新清單，整理與清理延後執行，等待自動儲存流程結束後才處理。過舊版本移至 Drive 垃圾桶。以下內容不立即清理：

- 手動另存的獨立備份。
- 尚有不同內容待選擇，或未完成上傳的資料集合。
- 本機同步基準或待上傳內容仍需參照的舊版本。

待選擇或待上傳處理完成後再回到上限。清理失敗不影響已保存內容，會提示並於下次讀取重試；不永久刪除。舊完整備份缺少同步基準時，可能追加一份紀錄建立基準，既有檔案不改寫。

## 自動整併與衝突任務

同步以雙方的最近共同版本為基準，比較各自修改：不同任務、同一任務不同欄位、不同子任務及不同設定可自動整併；同時新增的任務各自保留。一端調整順序、另一端只修改內容也可整併。日期只用於顯示，不依裝置時間決定哪份內容勝出。

同一任務的同一欄位改成不同內容、刪除與編輯相撞，或各自有效的日期整併後不合理時，右側欄「任務 → 衝突任務」保留待選版本；沒有衝突時隱藏整個區塊。右上側欄按鈕顯示數量，清單包含所有工作空間。按「比較與編輯」開啟完整任務版本，桌面並排、窄螢幕上下排列；可修改名稱、完整描述、專案、分類、狀態、優先順序、釘選、時程及子任務，再按該份的「儲存並採用這份」。每份選項已帶入其他可安全整併的欄位，不在主畫面增加重複任務。描述發生不同修改時保留各份原文，不自動拼接段落。

版本附上最近內容編輯的裝置來源與修改時間；未記錄時明確標示，不推測來源。在「設定 → 資料與備份」填寫本機裝置名稱後，後續內容修改會帶入此來源；名稱偏好不隨還原或同步被其他裝置取代。來源與時間只用於辨識，不決定哪份內容勝出。

等待選擇時，主畫面暫時保留共同內容及安全修改；點選該任務會開啟版本編輯器，草稿與採用選擇一次保存。其他任務仍可正常修改及同步。待選版本隨工作空間一起保存、匯出與同步，即使舊歷史備份已整理，內容也仍在最新資料中。選用後原選項留在已處理紀錄，可復原或重做；啟用同步並連線後，其他裝置會收到處理結果。編輯期間衝突、工作空間或原資料改變時，過期儲存會被阻擋，草稿仍留在編輯器。

已選用的紀錄繼續保存，避免離線裝置晚送回的已知舊版本再次產生同一衝突；選用後的新修改照常保留。兩台裝置同時選了不同版本或又修改了同一欄位時，重新列為待選任務，雙方內容保留。

整併後建立連接各個最新版本的新備份。上傳前檢查本機修訂與雲端版本，上傳後再確認最新內容；遇到同時上傳會再次整併，每次處理最多嘗試三輪。這是可接續的版本整併，沒有 Drive 檔案鎖；不能保證任何瞬間都只有一份最新檔案。短暫出現多個版本時，後續同步可繼續收斂，持續變動或無法判斷時保留副本並提示再次同步或選擇。

## 無法安全整併的內容

設定的同欄位分歧、互相衝突的排序、工作空間或分類／專案等引用失效，仍使用「遠端同步備份」的內容選擇。缺少最近共同版本或存在多個無法唯一判定的共同基準時，不猜測修改來源，也保留原有內容供選擇。本機會快取最近同步基準，讓歷史整理後仍有機會整併；舊裝置沒有快取且共同歷史已不可讀時，需手動接續。

目前使用的雲端資料有上述分歧時，暫停該集合的自動處理，並排提供「使用這台電腦的內容」和雲端選項，也可按「再次嘗試整併」。只有一份可選副本時，按「使用雲端內容」直接套用；有多份時，按「選擇雲端內容」展開清單，各份列出保存時間、工作空間與任務數，按「使用這份雲端內容」就立即套用，不再經過預覽確認。有可靠共同基準時，選定內容用來處理衝突欄位，其他安全修改仍一起整併；無法安全判斷時使用選定的完整內容。展開或收起清單不套用資料，處理中顯示「套用中…」。其他副本保留為過去備份。

這台電腦目前連結的雲端版本標為「目前副本」，依實際資料集合及版本判斷，並非單看保存時間。它代表最近接續或保存的雲端副本，尚未上傳的本機修改可能與它不同；若它已成為過去備份，標示會出現在過去備份清單中。

每份內容另有垃圾桶，也可先加入雲端工作空間副本再選本機。解決後建立連接雙方的新版本，舊內容保留；套用期間本機或雲端有新修改時停止處理，重新載入後再選擇。最多一次合併二十個分支，超過時先匯入需要的副本再建立新集合。

有多份最新內容時，可確認「刪除這份內容」，只將選定分支移至垃圾桶。其餘內容、歷史及本機資料保留；剩下唯一最新內容時不提供逐份刪除，以免誤刪整份資料。剩下內容與本機不同時先確認接續方式，重新載入會反映其他裝置的變更。

## Drive 資料夾與整理

```text
IIH Orbit/
  區塊維護紀錄.json
  同步資料/
  共用資料區塊/
  歷史備份/
    手動備份/
    自動備份/
    同步歷史/
```

每個集合的最新同步版本（含未解決分支）位於「同步資料」，已有後續版本的內容放在「同步歷史」。檔名包含用途、範圍名稱及 UTC 保存時間。

新檔案直接存入對應資料夾。舊集合及另存備份可於「檔案位置與整理」按「整理資料夾」，將最新同步內容放入「同步資料」、舊版本與手動備份放入「歷史備份」，並統一檔名。這個按鈕只調整位置與名稱，不修改 JSON 內容或刪除備份；保留檔案 ID、校驗及父版本關係，可重複執行，已在正確位置的略過。最近八份的自動保留規則由讀取清單或保存資料另行處理。整理失敗可單獨重試，不重新上傳已保存資料或搬回垃圾桶內容。

共用區塊可能同時被最新、歷史或分歧版本引用，不跟隨單份版本直接刪除。完整檢查確認沒有引用後，觀察 30 天，再於 Orbit 開啟且同步閒置時，每批最多 20 個移至 Drive 垃圾桶。重新被引用會取消原期限；長期未完成作業過期後，裝置可從本機完整資料重新建立區塊。清理失敗有獨立提示，已保存內容保留。這些檔案不列為獨立備份，不要單獨刪除；[觀察及回收細節](storage-sync-upgrade.md#未引用區塊的-30-天觀察)。

## 刪除與舊連結

「過去備份」及另外保存的備份預設收合，以日期時間辨識，每份均可確認後刪除。刪除整份雲端資料會先列出完整範圍；若目前正在使用，先停止自動保存、解除連結並取消該資料的待上傳內容，保留其他集合及本機資料。

所有刪除均移至 Drive 垃圾桶，Orbit 不永久刪除或清空垃圾桶。歷史的同步關係仍保留，避免刪除中間版本造成假衝突；整份刪除另保留停止同步識別，防止其他裝置重新建立該集合。本機任務與 Google Calendar 活動保留。

確認期間有新版本、待上傳內容、帳號或設定變更時須重新確認。部分刪除失敗可重新確認剩餘範圍並繼續，已移至垃圾桶的略過；檔案全部消失時可「清除舊連結」，再選已有資料或建立新的自動儲存。

重置或全部還原清理本機 Drive 狀態、基準與佇列、關閉自動處理，保留雲端檔案。之後須重新預覽接續。技術機制見 [資料儲存](data-storage.md)，實際驗證見 [QA](../QA.md)；真實 Drive API 與跨裝置操作由使用者手動驗收。

連結用途與混合排序會隨 JSON／雲端完整備份、分塊同步及工作空間副本保留。使用這些欄位後，接續裝置須支援雲端格式 7；衝突副本可先預覽每個任務的連結用途與編號順序，再決定採用。[第二階段資料規則](task-editor-information.md)。
