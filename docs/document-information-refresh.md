# 檔案資訊更新、存取狀態與快取整理

[文件索引](README.md) · [多個 Drive 檔案來源](drive-file-sources.md) · [任務雙欄與連結用途](task-editor-information.md)

2026-10-15：完成本輪第三階段。任務資訊連結、檔案側欄與選檔視窗共用檔案查驗結果；目錄、搜尋與選取仍各自獨立。

## 使用方式

開啟任務時先呈現保存的名稱與位置，背景只查驗目前可見且需要更新的 Drive 連結。取得新資訊後，名稱、類型圖示、外開 URL 與位置一起更新；檔案或上層資料夾改名、搬移均可反映。這些更新只影響顯示，不修改任務內容、用途、排序或修改時間。

資訊連結上方可選「自動選擇可用來源」或指定來源，再按「更新連結資訊」。此操作只處理目前可見的項目；捲動後可更新其他項目。有效快取在一般開啟時重用，手動更新可略過有效期限，但仍遵守服務限流。

主要來源的路徑起點為 Google Drive，額外來源使用自訂名稱。自動選擇最多嘗試三個已連線來源；指定來源只向該來源發出查驗。同檔案有另一個來源可讀取時，保留其成功資訊，並提示所選來源查驗未完成。來源需要授權時可按連線／重新授權；背景查驗不自行開啟授權視窗。

## 狀態與位置

| 顯示 | 意義與操作 |
| --- | --- |
| 可存取 | 已取得檔案資訊，旁邊顯示來源與上次查驗時間 |
| 尚未查驗／資訊已過期 | 先用保存快照或最後資訊，等待可見項目查驗 |
| 離線，保留上次資訊 | 保留名稱與連結，恢復連線後接續按需查驗 |
| 來源需要重新授權 | 由使用者按鈕續接該來源；未設定 Client ID 時提示至設定完成 |
| 已移至垃圾桶 | 服務明確回傳垃圾桶狀態，任務關聯與原服務入口保留 |
| 可能已刪除或權限變更 | 查驗無法讀取此檔案，可重查或改選來源；不逕自斷言已刪除 |
| 配額或服務忙碌，稍後重試 | 保留原資訊，遵守退避期限；反覆手動更新不會繞過限流 |
| 查驗未完成，保留上次資訊 | 網路或服務錯誤；服務未啟用／管理限制另提供設定提示 |

無法取得完整祖先、循環或深度／額度達上限時，路徑標示「部分位置」與無法確認完整路徑；不把任意無父項的檔案誤認為根目錄。捷徑顯示其所在位置，並註明目標位置尚未查驗，不額外追蹤目標檔案。

側欄與選檔的舊目錄快取若已有明確搬移或垃圾桶資訊，隱藏不再位於該處的項目；任務中的連結與計數保留。未查驗成功的項目不因錯誤自動解除關聯。Gmail 連結標示「原信連結，尚未主動查驗」，未加入郵件有效性查驗。

## 清除快取

「設定 → Google Drive → 檔案顯示快取」顯示檔案資訊、目錄列表與過期快取數量，可選：

- **清除過期快取**：移除已過期或已失效的可重建記錄。
- **清除全部檔案快取**：清除本次開啟期間的查驗與列表快取，停止未完成的舊回覆寫入。

完成後顯示實際清除筆數；一份檔案可能包含查驗、原始資訊及目錄等多筆快取，因此筆數不等於任務連結數。清理保留任務、用途、順序、文件身份、移除事件、來源連線與目前瀏覽位置。重新開啟或更新時再讀取；清除不解除服務限流。快取目前只存在分頁記憶體，重新載入也會重建。

此階段沒有刪除無使用的文件來源紀錄、壓縮歷史事件或移除遠端檔案；這些與快取清理不同，仍屬後續來源整理範圍。

## 請求與資料規則

| 項目 | 已實作的限制 |
| --- | --- |
| 成功資訊期限 | 15 分鐘；目錄列表維持原有 5 分鐘 |
| 自動觸發 | 共用可見性觀察器、來源／環境變更及前景每分鐘檢查；有效資訊不重查 |
| 去重與並行 | 同來源／檔案的進行中請求合併；每來源 2 筆、全體 4 筆 |
| 批次與祖先 | 每批 20 個連結；每次 refresh 最多 40 筆新的祖先查詢；追溯最多 12 層 |
| 有界快取 | 最多 1000 份查驗、2000 份檔案／祖先資訊及 1000 份錯誤記錄 |
| 失敗期限 | 無法存取暫存 5 分鐘，其他失敗至少 1 分鐘；到期重新讀取，不能用舊成功資訊假裝恢復 |
| 限流 | 來源共用指數退避，最長基礎退避 1 小時；每日限制至少 15 分鐘，較長 Retry-After 仍優先遵守 |

批次是排程單位，不代表二十份檔案只消耗一筆 API 查詢。新列表直接供共用快取使用，不為同批檔名補發逐檔查詢；父位置需要時才補讀。離線或分頁隱藏會取消查驗，回到前景只處理可見項目。帳號、Client ID、資料世代、來源與授權範圍隔離；續接新憑證會取消舊作業，晚到的查驗或舊列表不能覆蓋新資訊。

沿用 `drive.metadata.readonly`，僅呼叫 `files.get` 取得固定欄位的 metadata，以及原有 `files.list`；不下載內文或匯出檔案。不加入全硬碟索引或 changes 增量追蹤。欄位含名稱、MIME、URL、父項、硬碟 ID、resource key、垃圾桶與捷徑資訊。[Google files.get](https://developers.google.com/workspace/drive/api/reference/rest/v3/files/get)、[Files 欄位](https://developers.google.com/workspace/drive/api/reference/rest/v3/files)。404 可能是檔案不存在或沒有讀取權限；403 依原因區分檔案權限、授權與限流。[Google Drive 錯誤處理](https://developers.google.com/workspace/drive/api/guides/handle-errors)。

查驗與清理不寫入 BoardStore、復原紀錄、IndexedDB 工作資料或備份摘要，不觸發任務同步版本。維持第二階段看板格式 6、JSON／Drive 格式 7，無新增資料遷移。跨裝置看到新名稱的方式，是各裝置使用自己的可用來源查驗；授權與快取不隨任務同步。

## 驗證邊界

測試涵蓋重複引用去重、冷／暖快取、祖先改名搬移、部分位置、捷徑、多來源成功／失敗隔離、錯誤分類、限流、取消、晚到回覆及清理前後工作資料／摘要不變。獨立瀏覽器頁使用正式 Angular 編譯的任務連結、檔案列表與設定元件、真實 BoardStore，OAuth 與 Drive API 使用合成回覆；手機版面為瀏覽器尺寸與字級模擬。

真實 Google 多帳號授權、共用硬碟、實際網路延遲／流量、跨裝置及實體手機仍需驗收。測試結果與截圖見 [QA 紀錄](../QA.md)。
